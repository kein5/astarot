# ASTAROT 0.5.1

[日本語版](#astarot-051日本語版)

ASTAROT 0.5.1 is a maintenance release that fixes installer problems and layout glitches found after 0.5.0. On Windows, the installed app is now named ASTAROT too. Your settings and models carry over as they are. This release also reduces the traffic of WebView2, which the Windows version uses to display its screens. For details, read the "Less WebView2 traffic" section.

## 🏷️ The installed app is now named ASTAROT

On Windows, the display name in "Apps & features", the desktop and Start menu shortcuts and the details of the executable now say ASTAROT. On a new install, the install folder is also `ASTAROT`.

If you update from 0.5.0, the install location does not move. The app keeps using the settings and models in the `VRCT-VOX` folder. "Apps & features" still has one entry, and only its display name changes.

## ⬇️ Fixed the installer failing to download the app

Because the repository was renamed, the installer sometimes looked for the app's files in the old location and failed to download them. The installer and the update check in the app now download from the renamed repository.

## 🖥️ Fixed layout glitches

This release fixes these three glitches:

- The "Voice changer" name wrapped partway in the list on the left.
- At startup, the heading of the conversation area jumped for an instant.
- Items in the settings menu wrapped onto two lines, so their heights did not match.

## 🔒 Less WebView2 traffic

WebView2, which the Windows version uses to display its screens, made connections of its own apart from showing the app's screens: it requested settings for Edge's experimental features and checked for component updates again and again. This release stops the settings requests and checks for updates only right after startup.

The SmartScreen traffic, which checks for dangerous sites, is kept for safety. Windows diagnostic data is handled according to the "Diagnostic data" setting in Windows.

## 🎙️ speech.cpp now uses dedicated GPUs only

Settings → Speech recognition (ASR) → Inference device and Settings → Text to speech (TTS) → Inference device now offer only the CPU and dedicated GPUs. Integrated GPUs are not used. "Automatic" and "GPU" use a dedicated GPU, and if there is more than one, they pick the one with the most memory.

If your PC has no dedicated GPU, "Automatic" now runs on the CPU. If you chose and saved an integrated GPU in an earlier version, the setting shows "integrated graphics can't be used", so choose a device again. <!-- writing-exempt: quotes the UI text in locales/en.yml exactly -->

## 📖 The user guide moved and uses the ASTAROT name

The user guide has moved to `kein5.github.io/astarot`. Links in the app open the new location. The guide now calls the product ASTAROT throughout, and its button and setting names match the 0.5.0 screens.

## 🔧 Internal changes

- Updated the Python dependencies together and moved Python's ONNX Runtime to 1.32 (the ONNX Runtime bundled with the app stays at 1.31.0) (#498)
- Upgraded to websockets 17, numpy 2.4, psutil 7.2 and pycaw 20260927 (#500, #502, #499, #501)
- Fixed DeepL retries, the OCR model check and Ruff to go with the Python dependency updates (#546)
- Updated the npm dependencies together and matched the CSP hashes (#545)
- Moved sass, which only the build uses, to the development dependencies (#571)
- Upgraded to jotai 3.0 and TypeScript 7.0 (#496, #494)
- Updated the GitHub Actions dependencies (#488, #489, #490, #491)
- Made the ping test pass with websockets 17 too (#542)
- Removed timing assumptions from the core tests and fixed flaky tests (#548)
- Switched the release draft's title and download source to the ASTAROT repository (#538, #547)
- Pointed the repository and document links to `kein5/astarot` (#505, #532, #533, #570)
- Moved the design reference document over to the brand colors (#552)
- Fixed the horizontal logo and the brand board (#525)
- Added writing rules for Japanese and English (#524)
- Documented the list of tools used in development (#551)
- Recorded candidate voice models and sound event models (#443, #444)
- Merged the 0.5.0 changes from main back into develop and bumped the version for 0.5.1-beta.1 (#528, #529)

The full list of changes is in [CHANGELOG.md](https://github.com/kein5/astarot/blob/main/CHANGELOG.md#051---2026-11-18).

# ASTAROT 0.5.1（日本語版）

ASTAROT 0.5.1は0.5.0のあとに見つかったインストーラーの問題と表示の崩れを直した保守版です。Windowsではインストール後の名前もASTAROTに切り替わります。設定とモデルはそのまま引き継がれます。あわせて、Windows版で画面の表示に使うWebView2の通信を減らしました。詳しくは「WebView2の通信を減らしました」の節を読んでください。

## 🏷️ インストール後の名前がASTAROTになりました

Windowsの「アプリと機能」の表示名、デスクトップとスタートメニューのショートカット、実行ファイルの情報がASTAROTになります。新しくインストールする場合は、インストール先も`ASTAROT`のフォルダーになります。

0.5.0から更新する場合は、インストール先を動かしません。`VRCT-VOX`のフォルダーにある設定とモデルをそのまま使います。「アプリと機能」の項目は1つのまま、表示名だけが変わります。

## ⬇️ インストーラーが本体を取得できない問題を直しました

リポジトリの名前を変えた影響で、インストーラーが本体のファイルを古い場所へ取りに行き、取得に失敗することがありました。インストーラーと、アプリの中の更新の確認の取得先を、改名後のリポジトリに直しました。

## 🖥️ 画面の表示の崩れを直しました

次の3つを直しました。

- 左側の一覧で「ボイスチェンジャー」の名前が途中で折り返される
- 起動したときに、会話の欄の見出しが一瞬跳ねる
- 設定のメニューの項目が2行に折り返され、高さがそろわない

## 🔒 WebView2の通信を減らしました

Windows版で画面の表示に使うWebView2が、アプリの画面とは別に、Edgeの試験的な機能の設定を取りに行ったり、部品の更新の確認を何度も繰り返したりしていました。設定の取得を止め、更新の確認は起動した直後だけにしました。

危険なサイトを確かめるSmartScreenの通信は、安全のために残しています。Windowsの診断データの扱いは、Windowsの「診断データ」の設定に従います。

## 🎙️ speech.cppで使うGPUを独立GPUに絞りました

「設定」→「音声認識（ASR）」と「テキスト読み上げ（TTS）」→「推論デバイス」で選べるのを、CPUと独立GPUだけにしました。内蔵GPUは使いません。「自動」と「GPU」は独立GPUを使い、複数あればメモリの多いほうを選びます。

お使いのPCに独立GPUがない場合は、「自動」がCPUで動くようになります。以前の版で内蔵GPUを選んで保存していた場合は、「内蔵GPUのため選べません」と表示されるので、選び直してください。

## 📖 使い方ガイドの場所と名前をASTAROTにそろえました

使い方ガイドは`kein5.github.io/astarot`に移りました。アプリの中のリンクも新しい場所を開きます。ガイドの中の製品名をASTAROTにそろえ、ボタンや設定の名前を0.5.0の画面に合わせて直しました。
