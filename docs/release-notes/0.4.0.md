VRCT-VOX 0.4.0の正式版です。

このバージョンからは、次のバージョンへの更新をアプリの中でできます。ボイスチェンジャー（RVC）はNVIDIAのGPUがなくても使えるようになりました。

送信したメッセージや話した内容がログに書かれていた問題を直しました。0.2.0から0.3.0を使っていた方は、「プライバシーの修正」を読んでください。

使い方は[ユーザー向けドキュメント](https://kein5.github.io/VRCT-VOX/)にあります。

## 主な変更

### アプリの中で更新する

「設定」→「アップデート」の「更新を確認」で、新しいバージョンがあるか確かめられます。見つかったら「（バージョン）に更新して再起動」を押します。新しいバージョンはGitHubのリリースから取得し、署名を確かめてから入れます。設定と取得したモデルはそのまま残ります。

起動したときにも更新を確認します。新しいバージョンがあると、画面の上に「新しいバージョンが出ました！」と出ます。

アプリの中で更新できるかどうかは、入れ方で決まります。

| 入れ方 | 更新のしかた |
|---|---|
| Windowsのインストーラー版 | アプリの中で更新できます |
| LinuxのAppImage版 | アプリの中で更新できます（AppImageを書き込める場所に置いた場合） |
| WindowsのZIP版、Linuxのtar.gz版 | 新しいバージョンを知らせるだけです。リリースのページから入れてください |
| Linuxのdeb版、rpm版 | パッケージマネージャーで更新してください。アプリは更新を確認しません |

インストーラー版を更新しても、インストールのときに選んだ言語とエディション（GPU版かCPU版か）は変わりません。消したショートカットも作り直しません。

### ボイスチェンジャー（RVC）をGPUなしで使う

RVCの変換は、アプリに含まれる処理で行うようになりました。PythonとPyTorchの実行環境は使いません。

- NVIDIAのGPUがない場合は、CPU用の実行環境（約0.6 GB）を取得して、CPUで変換します。声の遅れは約1.3秒です。
- GPU用の実行環境はCUDA 13版になりました。大きさはWindowsで約1.8 GB、Linuxで約1.9 GBです（以前は約2.3 GBと約2.4 GB）。GPUでの声の遅れは約0.2秒です。
- 開始する前と変換している間、RVCのページに声の遅れの目安が出ます。変換中は、GPUとCPUのどちらで変換しているかも出ます。
- CPUの処理が追いつかないときは、崩れた声を流さずに変換を止めます。「変換が追いつかず停止しました」と知らせます。

### 起動してすぐメイン画面が出る

起動中の画面（スプラッシュ）をなくしました。起動するとすぐにメイン画面が出ます。準備が終わるまでは、操作できない状態で表示します。

- ウィンドウは、最初から通常の大きさで開きます。
- 起動中もOSの言語（日本語か英語）で表示します。途中で英語に切り替わることはありません。
- 起動に失敗したときは、理由と「もう一度起動する」のボタンを出します。

### 準備が足りない機能のスイッチ

メイン画面の機能のスイッチは、使うためのモデルや設定が足りない間は灰色になり、押せません。対象は「翻訳」「マイク入力」「聞き取り」「チャット読み取り（OCR）」「テキスト読み上げ（TTS）」「ボイスチェンジャー（RVC）」です。

- マウスを重ねると、足りないものと、それを用意する設定の場所が出ます。
- ウィンドウの幅が広いときは、スイッチの下に「設定を開く」か「取得内容を確認」のボタンが出ます。
- 用意ができると、再起動しなくても使えるようになります。

VRパネルのランチャーでも「翻訳」「マイク入力」「聞き取り」「チャット読み取り」のボタンが同じように灰色になります。足りないものと、デスクトップの設定のどこで用意するかを、VRの中で読めます。この説明は、VRの操作の吹き出しをオフにしていても出ます。

### プライバシーの修正

0.2.0から0.3.0では、送信したメッセージ、話した内容、その翻訳が診断用のログ（`process.log`）に書かれていました。0.4.0からは書きません。画面に出る内容は変わりません。

`process.log`は起動のたびに空になります。0.4.0を一度起動すると、以前のバージョンが書いた内容は残りません。以前のバージョンの`process.log`を不具合の報告などでほかの人に渡したことがある場合は、そのファイルに会話の内容が入っていた可能性があります。

### そのほか

- 同梱している音声認識のエンジン（speech.cpp）を0.11.0に更新しました。使い方と設定は変わりません。
- 配布物に、アプリが使うRustのライブラリのライセンス文を入れました。
- アプリの新しい処理部分を、試用として入れました。特別な指定をしたときだけ動き、ふだんの動作は変わりません。新しい処理部分への切り替えは0.5.0の予定です。

## 更新するときの注意

0.3.0から更新するときの注意です。

### 0.4.0の入れ方

0.3.0以前のバージョンには、アプリの中で更新する機能がありません。0.4.0はこのページから入れてください。0.4.0からは次のバージョンをアプリの中で更新できます。

### ボイスチェンジャー（RVC）

- 以前のバージョンで取得したRVCの実行環境（PyTorchを使う形式）は使えません。「このフォルダの実行環境は以前の形式のため、もう使えません」と出たら、「設定」→「ボイスチェンジャー（RVC）」→「モデルと実行環境」で取得し直してください。
- 取得し直した実行環境は同じフォルダに入るので、保存した設定はそのまま使えます。
- 取得が終わると、以前の形式のファイル（`venv`、`python`、`engine`など）を自動で消します。フォルダに置いたモデル（`.pth`、`.index`など）と音声のファイルは残ります。
- GPUで変換するには、NVIDIAのドライバー580以降と、GeForce GTX 16シリーズかRTX 20シリーズ以降のGPUが必要です。それより前の環境ではCPUで変換します（遅れは約1.3秒）。GPUで変換したい場合は、ドライバーを更新してください。

### 更新の確認

起動のたびにGitHubのリリースへ新しいバージョンを問い合わせます。送るのは通常のダウンロードと同じ情報で、会話や音声は送りません。止めるには、「設定」→「アップデート」の「起動時に更新を確認する」をオフにします。

### そのほか

設定と取得済みのモデルはそのまま使えます。

## 既知の問題

- WindowsのZIP版とLinuxのtar.gz版は、アプリの中で更新できません。新しいバージョンが出たことを知らせ、リリースのページへのリンクを出します。
- 起動の直後は、保存した表示の設定（UIの倍率、フォント、送信ボタンの表示など）が届くまで、既定の配置で表示します。設定によっては、準備が終わった時点で配置が変わります。
- CPUの負荷が高いと、RVCの変換が追いつかずに止まることがあります。GPUやCPUを使うほかのアプリを閉じてから、もう一度開始してください。
