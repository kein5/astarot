# VRCT-VOX 0.4.0

[日本語版](#vrct-vox-040日本語版)

This is the stable release of VRCT-VOX 0.4.0.

From this version on, you can update to the next version inside the app. The voice changer (RVC) now works without an NVIDIA GPU. On Windows, the app guides you through setting up a virtual microphone and lets you check that sound gets through.

This release fixes a problem where messages you sent and what you said were written to a log. If you used 0.2.0 to 0.3.0, read "Privacy fix".

The [user documentation](https://kein5.github.io/astarot/) explains how to use the app.

## Main changes

### Update inside the app

You can check whether a new version is available with "Check for updates" in Settings → Updater. If one is found, press "Update to (version) and restart". The new version is downloaded from the GitHub release, and its signature is checked before it is installed. Your settings and downloaded models stay as they are.

The app also checks for updates when it starts. If a new version is available, "New version is ready!" appears at the top of the screen.

Whether you can update inside the app depends on how you installed it.

| How you installed it | How to update |
|---|---|
| Windows installer | You can update inside the app |
| Linux AppImage | You can update inside the app (if you put the AppImage in a folder you can write to) |
| Windows ZIP, Linux tar.gz | The app only tells you about a new version. Install it from the releases page |
| Linux deb, rpm | Update with your package manager. The app does not check for updates |

Updating the installer version does not change the language and edition (GPU or CPU) you chose when you installed. Shortcuts you deleted are not created again.

### Use the voice changer (RVC) without a GPU

RVC conversion now runs in code that comes with the app. It does not use a Python and PyTorch runtime.

- Without an NVIDIA GPU, the app downloads the CPU runtime (about 0.6 GB) and converts on the CPU. The voice lags by about 1.3 seconds.
- The GPU runtime is now the CUDA 13 version. It is about 1.8 GB on Windows and about 1.9 GB on Linux (before, about 2.3 GB and about 2.4 GB). On the GPU the voice lags by about 0.2 seconds.
- Before you start and while it converts, the RVC page shows an estimate of the voice delay. While converting, it also shows whether the GPU or the CPU is doing the conversion.
- When the CPU cannot keep up, conversion stops without playing a garbled voice. The app tells you "Conversion could not keep up and stopped".

### Virtual microphone guide (Windows)

To get the voices of text to speech and the voice changer into VRChat, you need a virtual microphone (virtual cable). If no virtual cable is found at startup, the app shows you how to set one up. If you use only translation and captions, you do not need one.

- If there is no virtual cable, the guide shows the VB-CABLE download page and how to install it. Once you install it, the guide moves to the next step by itself.
- If there is a virtual cable, the guide shows the names of its playback side and recording side, and whether the text-to-speech output device is set to the playback side. It does not change your settings.
- When you press "Play the test sound", a short sound plays to the playback side, and a volume meter shows whether it reached the recording side. The test sound plays only when you press the button, and not while you are muted.
- Finally, the guide asks you to choose the recording side as your microphone in VRChat.

You can open the guide at any time with "Check the virtual microphone" under the output device in Settings → Text to speech (TTS). If you choose "Don't open this by itself again", it no longer opens at the next start. On Linux, the app creates the virtual microphone, so there is no guide. <!-- writing-exempt: quotes the UI label exactly as locales/en.yml had it in 0.4.0 -->

### Which speech recognition and text-to-speech models you can choose

- Speech recognition: you can download the 7 models that the bundled speech.cpp handles, choosing the file type (quantization) for each. You choose the model and the file type before downloading.
- Text to speech: you can now download Irodori-TTS Small, Irodori-TTS Large and Qwen3-TTS 1.7B. The model selected at first does not change.
- As before, the license and size are shown and you are asked to confirm before downloading. License links now show the file name.

Nemotron 3.5 Transcribe is 19 GB even in its smallest file, and it is not selected by default. Irodori-TTS Large is a model subject to the Gemma terms of use, and it is not the default either.

### Move the desktop captions

You can now move the desktop caption overlay while you hold down the Ctrl key.

- Drag while holding down Ctrl and a mouse button to move the captions. When you release Ctrl, mouse presses pass through to the window below, as before.
- Hold down Ctrl over the captions and press "+" or "-" to change the text size.
- The position and text size are saved and come back after a restart. You can reset them with Settings → VR → Desktop caption overlay → Reset the caption position and text size.

Captions in VR do not change.

### The main screen appears right after start

The startup screen (splash) is gone. The main screen appears as soon as the app starts. Until the app is ready, you can see the screen but cannot use it.

- The window opens at its normal size from the start.
- During startup the app is shown in the OS language (Japanese or English). It does not switch to English partway through.
- If startup fails, the app shows the reason and a "Try starting again" button.

### Switches for features that are not ready

Feature switches on the main screen are gray and cannot be pressed while a model or setting they need is missing. This applies to "Translation", "Mic input", "Listening", "Chat reading (OCR)", "Text to speech (TTS)" and "Voice changer (RVC)".

- When you hover the mouse over a switch, it shows what is missing and where in the settings to set it up.
- When the window is wide, an "Open settings" or "Review download" button appears under the switch.
- Once it is set up, you can use the feature without restarting.

In the VR UI launcher, the "Translate", "Mic input", "Listening" and "Chat reading (OCR)" buttons turn gray in the same way. In VR you can read what is missing and where in the desktop settings to set it up. This explanation appears even when you have turned off the button tooltips in VR.

### Privacy fix

In 0.2.0 to 0.3.0, messages you sent, what you said and its translations were written to the diagnostic log (`process.log`). From 0.4.0 on, they are not written. What appears on the screen does not change.

`process.log` is emptied at every start. Once you start 0.4.0, nothing that earlier versions wrote remains. If you gave a `process.log` from an earlier version to someone else, for example in a bug report, that file may have contained what was said in your conversations.

### Other changes

- The bundled speech recognition engine (speech.cpp) is updated to 0.11.0. How you use it and its settings do not change.
- The release package now includes the license texts of the Rust libraries the app uses.
- A new processing part of the app is included as a trial. It runs only when you specifically ask for it, and normal behavior does not change. The switch to the new processing part is planned for 0.5.0.

## When you update

These notes are for updating from 0.3.0.

### How to install 0.4.0

Versions 0.3.0 and earlier have no way to update inside the app. Install 0.4.0 from this page. From 0.4.0 on, you can update to the next version inside the app.

### Voice changer (RVC)

- The RVC runtime downloaded with an earlier version (the kind that uses PyTorch) cannot be used. If you see "The runtime in this folder is of an earlier kind and can no longer be used", download it again in Settings → Voice changer (RVC) → Models and runtime.
- The runtime you download again goes into the same folder, so your saved settings keep working.
- When the download finishes, the files of the earlier kind (`venv`, `python`, `engine` and others) are deleted automatically. Models (`.pth`, `.index` and others) and audio files you put in the folder stay.
- Converting on the GPU needs NVIDIA driver 580 or later and a GeForce GTX 16 series GPU, or an RTX 20 series GPU or later. On older setups, conversion runs on the CPU (with a delay of about 1.3 seconds). If you want to convert on the GPU, update your driver.

### Update checks

At every start, the app asks GitHub releases for a new version through a server of the VRCT-VOX developer (Cloudflare). It sends the same information as a normal download, and it does not send conversations or audio. To stop this, turn off Settings → Updater → Check for updates at start.

### Other notes

Your settings and downloaded models keep working as they are.

## Known issues

- The Windows ZIP and Linux tar.gz versions cannot update inside the app. They tell you that a new version is out and show a link to the releases page.
- Right after start, the app uses the default layout until your saved display settings (UI scale, font, whether the send button is shown and others) arrive. Depending on your settings, the layout changes when the app is ready.
- Under high CPU load, RVC conversion may fall behind and stop. Close other apps that use the GPU or CPU, then start again.

# VRCT-VOX 0.4.0（日本語版）

VRCT-VOX 0.4.0の正式版です。

このバージョンからは、次のバージョンへの更新をアプリの中でできます。ボイスチェンジャー（RVC）はNVIDIAのGPUがなくても使えるようになりました。Windowsでは、仮想マイクの用意を案内して音が届くかを確かめられます。

送信したメッセージや話した内容がログに書かれていた問題を直しました。0.2.0から0.3.0を使っていた方は、「プライバシーの修正」を読んでください。

使い方は[ユーザー向けドキュメント](https://kein5.github.io/astarot/)にあります。

## 主な変更

### アプリの中で更新する

「設定」→「アップデート」の「更新を確認」で、新しいバージョンがあるか確かめられます。見つかったら「（バージョン）に更新して再起動」を押します。新しいバージョンはGitHubのリリースから取得し、署名を確かめてから入れます。設定と取得したモデルはそのまま残ります。

起動したときにも更新を確認します。新しいバージョンがあると、画面の上に「新しいバージョンが出ました！」と出ます。

アプリの中で更新できるかどうかは、入れ方で決まります。

| 入れ方 | 更新のしかた |
|---|---|
| Windowsのインストーラー版 | アプリの中で更新できます |
| LinuxのAppImage版 | アプリの中で更新できます（AppImageを書き込める場所に置いた場合） |
| WindowsのZIP版、Linuxのtar.gz版 | 新しいバージョンを知らせるだけです。リリースのページから入れてください |
| Linuxのdeb版、rpm版 | パッケージマネージャーで更新してください。アプリは更新を確認しません |

インストーラー版を更新しても、インストールのときに選んだ言語とエディション（GPU版かCPU版か）は変わりません。消したショートカットも作り直しません。

### ボイスチェンジャー（RVC）をGPUなしで使う

RVCの変換は、アプリに含まれる処理で行うようになりました。PythonとPyTorchの実行環境は使いません。

- NVIDIAのGPUがない場合は、CPU用の実行環境（約0.6 GB）を取得して、CPUで変換します。声の遅れは約1.3秒です。
- GPU用の実行環境はCUDA 13版になりました。大きさはWindowsで約1.8 GB、Linuxで約1.9 GBです（以前は約2.3 GBと約2.4 GB）。GPUでの声の遅れは約0.2秒です。
- 開始する前と変換している間、RVCのページに声の遅れの目安が出ます。変換中は、GPUとCPUのどちらで変換しているかも出ます。
- CPUの処理が追いつかないときは、崩れた声を流さずに変換を止めます。「変換が追いつかず停止しました」と知らせます。

### 仮想マイクの案内（Windows）

読み上げとボイスチェンジャーの声をVRChatに届けるには、仮想マイク（仮想ケーブル）が要ります。起動したときに仮想ケーブルが1つも見つからなければ、用意のしかたを案内します。翻訳と字幕だけを使う場合は要りません。

- 仮想ケーブルがなければ、VB-CABLEの配布ページと入れ方を示します。入れると、案内が自動で次へ進みます。
- 仮想ケーブルがあれば、再生側と録音側の名前と、読み上げの出力デバイスが再生側になっているかを示します。設定は変えません。
- 「テスト音を流す」を押すと、短い音を再生側へ流し、録音側に届いたかを音量のメーターで示します。テスト音は押したときだけ流し、ミュート中は流しません。
- 最後に、VRChatのマイクに録音側を選ぶよう案内します。

「設定」→「テキスト読み上げ（TTS）」の出力デバイスの下にある「仮想マイクを確かめる」から、いつでも開けます。「今後は自動で表示しない」を選ぶと、次からは起動しても開きません。Linuxでは、アプリが仮想マイクを作るので案内しません。

### 音声認識と読み上げのモデルを選べる範囲

- 音声認識：同梱のspeech.cppが扱う7種類のモデルを、ファイルの種類（量子化）ごとに選んで取得できます。取得する前に、モデルとファイルの種類を選びます。
- 読み上げ：Irodori-TTS Small、Irodori-TTS Large、Qwen3-TTS 1.7Bを取得できるようになりました。最初に選ばれているモデルは変わりません。
- 取得する前に、これまでどおりライセンスとサイズを示して確認を求めます。ライセンスのリンクは、ファイルの名前で示すようにしました。

Nemotron 3.5 Transcribeはいちばん小さいファイルでも19 GBあり、既定では選ばれません。Irodori-TTS LargeはGemmaの利用規約に従うモデルで、これも既定にしていません。

### デスクトップの字幕を動かす

デスクトップの字幕オーバーレイを、Ctrlキーを押しながら動かせるようになりました。

- Ctrlキーとマウスのボタンを押したままドラッグすると、字幕の位置が変わります。Ctrlキーを離すと、これまでどおりクリックを下のウィンドウに通します。
- 字幕の上でCtrlキーを押したまま「+」か「-」を押すと、文字の大きさが変わります。
- 位置と文字の大きさは保存され、再起動しても戻ります。「設定」→「VR」→「デスクトップの字幕オーバーレイ」の「字幕の位置と文字の大きさを初期に戻す」で戻せます。

VRの字幕は変わりません。

### 起動してすぐメイン画面が出る

起動中の画面（スプラッシュ）をなくしました。起動するとすぐにメイン画面が出ます。準備が終わるまでは、操作できない状態で表示します。

- ウィンドウは、最初から通常の大きさで開きます。
- 起動中もOSの言語（日本語か英語）で表示します。途中で英語に切り替わることはありません。
- 起動に失敗したときは、理由と「もう一度起動する」のボタンを出します。

### 準備が足りない機能のスイッチ

メイン画面の機能のスイッチは、使うためのモデルや設定が足りない間は灰色になり、押せません。対象は「翻訳」「マイク入力」「聞き取り」「チャット読み取り（OCR）」「テキスト読み上げ（TTS）」「ボイスチェンジャー（RVC）」です。

- マウスを重ねると、足りないものと、それを用意する設定の場所が出ます。
- ウィンドウの幅が広いときは、スイッチの下に「設定を開く」か「取得内容を確認」のボタンが出ます。
- 用意ができると、再起動しなくても使えるようになります。

VRパネルのランチャーでも「翻訳」「マイク入力」「聞き取り」「チャット読み取り（OCR）」のボタンが同じように灰色になります。足りないものと、デスクトップの設定のどこで用意するかを、VRの中で読めます。この説明は、VRの操作の吹き出しをオフにしていても出ます。

### プライバシーの修正

0.2.0から0.3.0では、送信したメッセージ、話した内容、その翻訳が診断用のログ（`process.log`）に書かれていました。0.4.0からは書きません。画面に出る内容は変わりません。

`process.log`は起動のたびに空になります。0.4.0を一度起動すると、以前のバージョンが書いた内容は残りません。以前のバージョンの`process.log`を不具合の報告などでほかの人に渡したことがある場合は、そのファイルに会話の内容が入っていた可能性があります。

### そのほか

- 同梱している音声認識のエンジン（speech.cpp）を0.11.0に更新しました。使い方と設定は変わりません。
- 配布物に、アプリが使うRustのライブラリのライセンス文を入れました。
- アプリの新しい処理部分を、試用として入れました。特別な指定をしたときだけ動き、ふだんの動作は変わりません。新しい処理部分への切り替えは0.5.0の予定です。

## 更新するときの注意

0.3.0から更新するときの注意です。

### 0.4.0の入れ方

0.3.0以前のバージョンには、アプリの中で更新する機能がありません。0.4.0はこのページから入れてください。0.4.0からは次のバージョンをアプリの中で更新できます。

### ボイスチェンジャー（RVC）

- 以前のバージョンで取得したRVCの実行環境（PyTorchを使う形式）は使えません。「このフォルダの実行環境は以前の形式のため、もう使えません」と出たら、「設定」→「ボイスチェンジャー（RVC）」→「モデルと実行環境」で取得し直してください。
- 取得し直した実行環境は同じフォルダに入るので、保存した設定はそのまま使えます。
- 取得が終わると、以前の形式のファイル（`venv`、`python`、`engine`など）を自動で消します。フォルダに置いたモデル（`.pth`、`.index`など）と音声のファイルは残ります。
- GPUで変換するには、NVIDIAのドライバー580以降と、GeForce GTX 16シリーズかRTX 20シリーズ以降のGPUが必要です。それより前の環境ではCPUで変換します（遅れは約1.3秒）。GPUで変換したい場合は、ドライバーを更新してください。

### 更新の確認

起動のたびに、VRCT-VOXの開発者のサーバー（Cloudflare）を通してGitHubのリリースへ新しいバージョンを問い合わせます。送るのは通常のダウンロードと同じ情報で、会話や音声は送りません。止めるには、「設定」→「アップデート」の「起動時に更新を確認する」をオフにします。

### そのほか

設定と取得済みのモデルはそのまま使えます。

## 既知の問題

- WindowsのZIP版とLinuxのtar.gz版は、アプリの中で更新できません。新しいバージョンが出たことを知らせ、リリースのページへのリンクを出します。
- 起動の直後は、保存した表示の設定（UIの倍率、フォント、送信ボタンの表示など）が届くまで、既定の配置で表示します。設定によっては、準備が終わった時点で配置が変わります。
- CPUの負荷が高いと、RVCの変換が追いつかずに止まることがあります。GPUやCPUを使うほかのアプリを閉じてから、もう一度開始してください。
