# ASTAROT 0.5.2

[日本語版](#astarot-052日本語版)

ASTAROT 0.5.2 is a fix release for a problem where the app crashed while you used it in VR. Your settings and models carry over as they are.

## 🥽 Fixed a crash when you used controllers in VR

If you used the subtitle overlay or the VR UI, the app crashed right after SteamVR's controllers became ready to use (#610). The problem happened in 0.5.0 and 0.5.1. The Windows event log records it as a fault in SteamVR's `vrclient_x64.dll` with exception code `0xc0000005`.

The cause was in the app: instead of the SteamVR function that reads the controller state, it called a different one. It now calls the right function.

If you turned off the subtitle overlay or the VR UI to avoid the crash, you can turn them back on after you update to 0.5.2.

## 🐞 Known issues

In 0.5.0 and 0.5.1 the app crashed before the controllers could be used. For that reason, it has not yet been checked on real hardware whether actions such as pointing at the VR UI with the laser, pressing and grabbing work correctly.

## 🔧 Internal changes

- Declared each OpenVR function table position together with the function's name, and added a test that checks them against pyopenvr's function tables (#613)
- Switched the source of ONNX Runtime from GitHub to NuGet (for building the release package and preparing the RVC runtime; the version stays at 1.31.0) (#609)

The full list of changes is in [CHANGELOG.md](https://github.com/kein5/astarot/blob/main/CHANGELOG.md#052---2026-11-18).

# ASTAROT 0.5.2（日本語版）

ASTAROT 0.5.2はVRで使っているときにアプリが落ちる問題を直した修正版です。設定とモデルはそのまま引き継がれます。

## 🥽 VRでコントローラーを使うとアプリが落ちる問題を直しました

字幕オーバーレイかVR UIを使っていると、SteamVRのコントローラーが使える状態になった直後にアプリが落ちていました（#610）。0.5.0と0.5.1で起きていた問題です。Windowsのイベントログでは、SteamVRの`vrclient_x64.dll`で例外コード`0xc0000005`の障害が起きたと記録されます。

原因はアプリの側にあり、コントローラーの状態を読む機能の代わりにSteamVRの別の機能を呼び出していました。正しい機能を呼ぶように直しました。

落ちるのを避けるために字幕オーバーレイやVR UIをオフにしていた場合は、0.5.2に更新したあとでオンに戻せます。

## 🐞 既知の問題

0.5.0と0.5.1ではコントローラーで操作する前にアプリが落ちていたため、VR UIをレーザーで指す、押す、掴むといった操作が正しく動くかを実機でまだ確かめていません。

## 🔧 内部の変更

- OpenVRの関数表の位置を関数の名前と一緒に宣言し、pyopenvrの関数表と照らし合わせる試験を足した（#613）
- ONNX Runtimeの取得元をGitHubからNuGetに切り替えた（配布物のビルドとRVCの実行環境の準備。版は1.31.0のまま）（#609）

すべての変更は [CHANGELOG.md](https://github.com/kein5/astarot/blob/main/CHANGELOG.md#052---2026-11-18) にあります。
