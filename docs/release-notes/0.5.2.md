ASTAROT 0.5.2はVRで使っているときにアプリが落ちる問題を直した修正版です。利用者に関係のある変更はこの修正だけです。設定とモデルはそのまま引き継がれます。

## 🥽 VRでコントローラーを使うとアプリが落ちる問題を直しました

字幕オーバーレイかVR UIを使っていると、SteamVRのコントローラーが使える状態になった直後にアプリが落ちていました（#610）。0.5.0と0.5.1で起きていた問題です。Windowsのイベントログでは、SteamVRの`vrclient_x64.dll`で例外コード`0xc0000005`の障害が起きたと記録されます。

原因はアプリの側にあり、コントローラーの状態を読む機能の代わりにSteamVRの別の機能を呼び出していました。正しい機能を呼ぶように直しました。

落ちるのを避けるために字幕オーバーレイやVR UIをオフにしていた場合は、0.5.2に更新したあとでオンに戻せます。

## 🐞 既知の問題

0.5.0と0.5.1ではコントローラーで操作する前にアプリが落ちていたため、VR UIをレーザーで指す、押す、掴むといった操作が正しく動くかを実機でまだ確かめていません。

## 🔧 内部の変更

- OpenVRの関数表の位置を関数の名前と一緒に宣言し、pyopenvrの関数表と照らし合わせる試験を足した（#613）

すべての変更は [CHANGELOG.md](https://github.com/kein5/astarot/blob/main/CHANGELOG.md#052---2026-11-18) にあります。
