# ASTAROT 0.5.0

[日本語版](#astarot-050日本語版)

ASTAROT 0.5.0 renames VRCT-VOX to ASTAROT and renews its screens. The release files are much smaller, and the app takes much less time to start. This release also fixes a problem where a bundled library sent usage data to an outside party. For details, read the "Stopped sending usage data" section.

## ✨ A new name and new screens

The app's display name is now ASTAROT. The screen layout has also been reworked: in the list on the left, icon buttons take you straight to the settings of each feature. Where the settings are saved and the internal identifiers have not changed, so you can keep using your existing settings as they are.

## 🚀 A lighter app

The release files are much smaller. The figures below compare with 0.4.0.

- Release ZIP: 389.8 MB → 34.5 MB (91.2% smaller)
- Size after extracting: 1,063.6 MB → 97.4 MB (90.8% smaller)

## 🎙️ Choose models from the model catalog

You can now choose speech recognition and text to speech (TTS) models from a catalog and download them. There are 7 speech recognition models and 6 TTS models. You can also add models you prepared yourself to the catalog and switch to them the same way as to the official models.

External TTS engines such as VOICEVOX and COEIROINK now have their own group in the catalog. You get each engine from its official website and connect to it.

## 🔷 Hexagram overlay

You can open each feature from a hexagram menu hidden at the edge of the screen. When you move the mouse over it, the features slide out, and scrolling rotates it. It is an experimental feature, so it is off by default. To use it, turn it on in Settings.

## 🧰 Closing the window puts the app in the tray

When you close the main window, the app does not quit; it goes to the tray. To quit, choose "Quit" from the tray menu. On systems without tray support, closing the window quits the app.

## 🔒 Stopped sending usage data

ONNX Runtime, a library bundled with the app, sent usage data to Microsoft when you started using a feature such as Chat reading (OCR). The app's "Send usage data" setting did not stop this traffic, so ASTAROT now stops it by changing the library's own settings. 0.5.0 does not send this data.

Files created when you used an earlier version (such as deviceid) may remain on your PC. Even if they remain, 0.5.0 sends nothing.

## ⚠️ When you update

- Only the installer version can update from inside the app. For the ZIP version, download the new version from the download page.
- The old voice changer runtime that earlier versions bundled (about 8 GB) is deleted automatically, but only if the app put it in place.
- If you use CUDA for the voice changer, you need NVIDIA driver 580 or later, because the app moved to CUDA 13.
- Seed-VC has been retired, and the voice changer now uses RVC only.
- API keys are now saved in a separate place from the settings file.

## 🐞 Known issues

- At the moment startup finishes, the heading in the middle of the screen may shift up or down for an instant. Its final position is correct.
- At the default window size, the "Voice changer" label in the list on the left may wrap.
- Even when the app is set to Japanese, it shows English for a moment right after it starts.

## 🔧 Internal changes

- Moved the app's processing from the Python backend to the Rust core (`native/`) and removed the Python runtime from the release package (#410)
- Made the VR overlay and the VR UI run in the core, and added a crate for SteamVR overlays (#410)
- Moved the audio device list, device selection and following the default device to the core (#410)
- Shipped both the CPU and the Vulkan builds of speech.cpp in the Linux package (#410)
- Pinned the version of the reading dictionary (SudachiDict) that is downloaded (#410)
- Unified requests to translation providers behind a trait resolved at compile time (#410)
- Added a development tool that exports translation models in float32, float16, int8 and int4 (#410)
- Made the core answer the settings endpoints of features it does not have yet (#367)
- Made every experimental feature switch a saved setting that is off by default (#377)
- Shared one OpenVR connection per process and made the scene application readable (#408)
- Added a way to download the ONNX Runtime and OpenVR libraries with pinned hashes and bundle them (#510)
- Started moving the UI to TypeScript (ADR-010) and added the vanilla-extract and Radix foundations (#370)
- Moved the layout skeleton of the main window to the ADR-010 foundation (#378)
- Removed unused UI templates, helper functions and strings (#404)
- Pinned Node.js for development and CI to 26.13.1 (#373)
- Stabilized tests that depend on time and tests that use fake servers (#376, #410)
- Put together the ASTAROT brand assets (icon, wordmark, brand board) (#365, #368, #438)
- Prepared the documents, the site and the repository for the rename (#366)
- Updated the README, the developer documents and the spec for the Rust core and the ASTAROT name (#385, #479, #483, #485, #514)
- Opened the ASTAROT user guide site (#372)

- Documented the accessibility policy (#506)

- Bumped the version for 0.5.0-beta.1 to beta.6 (#419, #450, #481, #504, #513, #526)

# ASTAROT 0.5.0（日本語版）

ASTAROT 0.5.0では、VRCT-VOXからASTAROTへ名前と画面を刷新しました。配布ファイルの大きさと起動にかかる時間も大きく減らしています。あわせて、同梱ライブラリが利用状況を外部へ送っていた問題を直しました。詳しくは「送信を止めました」の節を読んでください。

## ✨ 名前と画面が生まれ変わりました

表示名がASTAROTになりました。画面の構成も見直し、左側の一覧ではアイコンのボタンから各機能の設定へ直接移動できます。設定の保存先や内部の識別子は変わっていないため、これまでの設定はそのまま使えます。

## 🚀 軽くなりました

配布ファイルの大きさを大きく減らしました。0.4.0との比較です。

- 配布ZIP：389.8 MB → 34.5 MB（91.2%減）
- 展開後の大きさ：1,063.6 MB → 97.4 MB（90.8%減）

## 🎙️ モデルカタログから選べます

音声認識と音声合成のモデルを、カタログから選んで取得できるようになりました。音声認識は7種、音声合成は6種です。自分で用意したモデルをカタログへ登録して、公式のモデルと同じ操作で切り替えることもできます。

VOICEVOXやCOEIROINKなどの外部の音声合成エンジンは、カタログの別の分類にまとめました。各エンジンの公式サイトから入手して、接続して使います。

## 🔷 六芒星のオーバーレイ

画面の端に隠れている六芒星のメニューから、各機能を呼び出せます。マウスを合わせると機能がせり出し、スクロールで回転します。実験的機能のため、初期状態では無効です。使うときは設定で有効にしてください。

## 🧰 閉じるとトレイにしまいます

メイン画面を閉じると、アプリは終了せずにトレイへ入ります。終了するときは、トレイのメニューから「終了」を選んでください。トレイに対応していない環境では、閉じるとアプリが終了します。

## 🔒 送信を止めました

同梱している ONNX Runtime というライブラリが、チャット読み取りなどの機能を使い始めたときに、利用状況を Microsoft へ送っていました。アプリの「利用状況を送信する」の設定では止まらない送信だったため、ライブラリの設定そのものを変えて止めました。0.5.0では、この送信は行われません。

過去のバージョンを使ったときに作られたファイル（deviceid など）が、お使いのPCに残っている場合があります。ファイルが残っていても、0.5.0から送信されることはありません。

## ⚠️ 更新するときの注意

- アプリの中で更新できるのはインストーラー版です。ZIP版は、配布ページから新しい版を取得してください。
- 以前のバージョンに同梱していた古い音声変換のランタイム（約8 GB）は、アプリが配置したものに限って自動で削除します。
- 声質変換に CUDA を使う場合は、NVIDIA のドライバー 580 以上が必要です。CUDA 13 へ移行したためです。
- Seed-VC は廃止し、声質変換は RVC に一本化しました。
- API キーは、設定ファイルとは別の場所に保存するようになりました。

## 🐞 既知の問題

- 起動が終わる瞬間に、画面中央の見出しが一瞬だけ上下にずれることがあります。最終的な位置は正しい状態です。
- 既定の窓の大きさでは、左側の一覧で「ボイスチェンジャー」の文字が折り返すことがあります。
- 日本語の設定でも、起動直後の一瞬だけ英語で表示されます。

## 🔧 内部の変更

- アプリの処理を Python のバックエンドから Rust の中核（`native/`）へ移し、配布物から Python の実行環境を外した（#410）
- VR のオーバーレイと VR パネルを中核で動かし、SteamVR のオーバーレイ用のクレートを足した（#410）
- 音声デバイスの一覧と選択と既定のデバイスへの追従を中核へ移した（#410）
- Linux の配布物に speech.cpp の CPU 版と Vulkan 版を一緒に入れるようにした（#410）
- 読みの辞書（SudachiDict）を版を固定して取得するようにした（#410）
- 翻訳プロバイダーへの要求をコンパイル時に解決するトレイトで共通化した（#410）
- 翻訳モデルを float32、float16、int8、int4 で書き出す開発用の道具を足した（#410）
- 中核にまだない機能の設定のエンドポイントにも中核が応えるようにした（#367）
- 実験的機能の切り替えを、すべて既定でオフの設定として保存するようにした（#377）
- OpenVR の接続をプロセスで1つにまとめ、シーンのアプリを読めるようにした（#408）
- ONNX Runtime と OpenVR のライブラリを固定したハッシュで取得して同梱する仕組みを足した（#510）
- UI の TypeScript への移行（ADR-010）を始め、vanilla-extract と Radix の基盤を入れた（#370）
- メイン画面のレイアウトの骨組みを ADR-010 の基盤へ移した（#378）
- 使っていない UI のテンプレートと補助関数と文言を外した（#404）
- 開発と CI の Node.js を 26.13.1 に固定した（#373）
- 時間に依存する試験と偽のサーバーを使う試験を安定させた（#376、#410）
- ASTAROT のブランドの素材（アイコン、ワードマーク、ブランドボード）を整えた（#365、#368、#438）
- 名前の変更に向けて、文書とサイトとリポジトリの準備をした（#366）
- README、開発者向けの文書、仕様書を Rust の中核と ASTAROT の名前に合わせた（#385、#479、#483、#485、#514）
- ASTAROT の利用者向けマニュアルのサイトを開いた（#372）
- リリースノートを利用者向けの変更と内部の変更に分ける書式にした（#369）
- アクセシビリティの方針を文書にした（#506）
- 音声 AI の実行環境を集約する原則を ADR-012 として採用した（#508）
- 0.4.0 の変更を main から develop へ戻した（#395）
- 0.5.0-beta.1 から beta.6 までの版を上げた（#419、#450、#481、#504、#513、#526）
