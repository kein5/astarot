# Getting help

[日本語版](#困ったときは日本語)

ASTAROT is maintained by one person on a best-effort basis. Replies may take some time, and there is no support channel outside GitHub.

| You want to… | Go to |
|---|---|
| Learn how to install, set up or use the app | The user guide: [English](https://kein5.github.io/astarot/en/) / [日本語](https://kein5.github.io/astarot/ja/) |
| Find out how the app helps if hearing, speaking or reading is hard for you, and what it cannot do yet | [ACCESSIBILITY.md](ACCESSIBILITY.md) |
| Fix something that does not work | [Troubleshooting](https://kein5.github.io/astarot/en/guide/troubleshooting) first, then a [bug report](https://github.com/kein5/astarot/issues/new?template=bug_report.yml) |
| Ask for a new feature or an improvement | A [feature request](https://github.com/kein5/astarot/issues/new?template=feature_request.yml) |
| Report a security vulnerability | Privately, as described in [SECURITY.md](SECURITY.md). Do not open a public issue. |

If the guide does not answer a question about using the app, open a bug report and describe what you tried and what you expected; a gap in the guide is treated as a bug in the guide.

Before you open an issue, search the [existing issues](https://github.com/kein5/astarot/issues?q=is%3Aissue) in case it has already been reported. Write in English or Japanese. Remove personal data, such as voice recordings, chat text, API keys and log lines you have not checked, from anything you attach.

ASTAROT (formerly VRCT-VOX) is derived from [VRCT](https://github.com/misyaguziya/VRCT) but is a separate project. Do not send ASTAROT questions to the VRCT maintainers.

Please follow the [code of conduct](CODE_OF_CONDUCT.md) in issues and pull requests. To contribute code or documentation, see [CONTRIBUTING.md](CONTRIBUTING.md).

## 困ったときは（日本語）

ASTAROT は1人で、できる範囲で保守しています。返事に時間がかかることがあります。GitHub のほかに問い合わせ先はありません。

| したいこと | 行き先 |
|---|---|
| 入れ方、設定、使い方を知りたい | [ガイド](https://kein5.github.io/astarot/ja/) |
| 聞くことや話すこと、文字を読むことを助ける機能と、まだできないことを知りたい | [ACCESSIBILITY.md](ACCESSIBILITY.md#アクセシビリティ日本語) |
| うまく動かない | まず[トラブルシューティング](https://kein5.github.io/astarot/ja/guide/troubleshooting)を見て、解決しなければ[不具合の報告](https://github.com/kein5/astarot/issues/new?template=bug_report.yml) |
| 機能を追加・改善してほしい | [機能の要望](https://github.com/kein5/astarot/issues/new?template=feature_request.yml) |
| 脆弱性を見つけた | [SECURITY.md](SECURITY.md) の手順で非公開で報告する（公開の Issue には書かない） |

使い方の疑問がガイドで解決しないときは、不具合の報告として出してください。試したことと期待した結果を書いてもらえれば、ガイドの不足として扱います。

Issue を出す前に、同じ内容の[既存の Issue](https://github.com/kein5/astarot/issues?q=is%3Aissue) がないか探してください。英語でも日本語でも構いません。添付するものからは音声、チャットの本文、API キー、中身を確かめていないログなどの個人情報を取り除いてください。

ASTAROT（旧名 VRCT-VOX）は [VRCT](https://github.com/misyaguziya/VRCT) から派生した別のプロジェクトです。ASTAROT についての質問を本家 VRCT の開発者に送らないでください。

Issue や PR では[行動規範](CODE_OF_CONDUCT.md)を守ってください。コードや文書で協力したい場合は [CONTRIBUTING.md](CONTRIBUTING.md) を見てください。
