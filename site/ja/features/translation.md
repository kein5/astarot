# 翻訳

入力した文章や、音声認識で文字にした発言を翻訳します。メイン画面の「翻訳」でオンとオフを切り替え、「翻訳エンジン」でエンジンを選びます。設定は「設定」→「翻訳」にあります。

自分の発言はメイン画面の「相手の言語」に、相手の発言は「あなたの言語」に訳します。

![「設定」→「翻訳」の画面](/screenshots/ja/translation.webp)

## 必要なもの

ローカル翻訳には使うモデルを用意します。外部の翻訳APIを使う場合は、提供元が求める情報を用意します。

## 操作

### PCの中で翻訳する

お使いのPCの中で翻訳するので、文章を外へ送りません。「AI翻訳（ローカル）」の「モデルと処理デバイス」を開き、「翻訳モデル」でモデルを選びます。

一覧に並ぶのは、ダウンロード済みのモデル、ダウンロードできるモデル、自分で追加したモデルです。まだ取得していないモデルは「取得内容を確認」を押します。提供元・ライセンス・容量を確かめる画面が開くので、同意してから取得します。[初期設定](../guide/first-setup)の画面からも、翻訳のモデルを選んで取得できます。

- いま選んでいるモデルは、ダウンロードできなくても「まだ取得できません」と付いて一覧に残ります。
- ダウンロードできるモデルが1つもなく、選んでいるモデルも使えないときは、その旨が出ます。翻訳には「詳細設定」の外部の翻訳APIかローカルLLMを使ってください。

カタログで取得できるのはM2M100 418M、NLLB-200 distilled 600M、NLLB-200 distilled 1.3Bのint8版です。表には、アプリが扱えるほかのモデルの容量も載せています。

| モデル | 容量の目安（int8） | ライセンス |
|---|---|---|
| M2M100 418M · int8（既定） | 506 MB | MIT（商用利用可） |
| M2M100 1.2B · int8 | 1.3 GB | MIT（商用利用可） |
| NLLB-200 distilled 600M · int8 | 643 MB | CC-BY-NC-4.0（非商用） |
| NLLB-200 distilled 1.3B · int8 | 1.4 GB | CC-BY-NC-4.0（非商用） |

::: warning NLLBは非商用ライセンスです
NLLBのモデルは商用目的では使えません。選ぶときや取得するときに確認が出るので、ライセンスを読んで同意したときだけ使えます。
:::

モデルによって翻訳できない言語があります。たとえばM2M100はバスク語とテルグ語に対応していません。対応していない言語を選んでいると、警告が出て選択が元に戻るので、言語を選び直します。

「AI翻訳の処理デバイス」ではCPUとGPUのどちらで翻訳するかを選べます。GPUで翻訳するには、同じ欄の「GPUで翻訳するためのONNX Runtime」で、CUDA版かDirectML版（Windows）を取得します。お使いのGPUに合う方には「お使いのGPU向け」と出ます。取得の前に、提供元・ライセンス・容量を確かめて同意します。取得したら処理デバイスで選び、ASTAROTを再起動します。GPUで動かせないモデルはCPUで動きます。

### 外部の翻訳APIを使う

DeepL、PLaMo、Gemini、OpenAI、Groq、OpenRouter、Google Cloud Translation、Papago Translation（NAVER Cloud Platform）を使えます。使うサービスの認証情報（PapagoはクライアントIDとクライアントシークレット）を登録してから、メイン画面の「翻訳エンジン」で選びます。

- 翻訳する文章は選んだサービスへ送られます。
- LLMのエンジン（Gemini、OpenAI、Groq、OpenRouter、ローカルLLMなど）には、翻訳する文のほかに、直近の会話を最大5件、言った時刻を付けて送ります。用語辞書の語のうち文に出てくるものも、名前として伝えます。
- APIキーはOSの資格情報の保管場所（Windowsは資格情報マネージャー、LinuxはSecret Service）に置き、設定ファイル（`config.json`）には書きません。Linuxで鍵束（GNOME KeyringやKWalletなど）が動いていないか、ロックされているときは、入れたキーはアプリを閉じるまでしか使えません。

「詳細設定」の「LLMのエンジンへの指示」では、訳のぶれの大きさ（「Temperature」）と、プロンプトに足す「追加の指示」（例:「敬語を使わずに訳す」）を決められます。どちらもLLMのエンジンにだけ送ります。

### ローカルLLMと互換サーバーを使う

LM Studio、Ollama、OpenAI互換のエンドポイントを使えます。自分で用意したモデルもこれらのサーバーに入れれば使えます（[自分のモデルを使う](../guide/custom-models#translation)）。「接続確認」でつながるかを確かめてからモデルを選んでください。OpenAI互換のエンドポイントに公式以外のURLを指定するときは、料金・セキュリティ・互換性をご自身で確認してください。

保存済みのAPIキーがある状態でURLを変えると、キーの入れ直しを求められます。保存済みのキーが別のサーバーへ送られないようにするためです。キーが必要ないサーバーに変えるときは、先に保存済みのキーを削除してください。

### 翻訳のカタログに自分のモデルやAPIを足す

「設定」→「翻訳」の「翻訳のカタログ」には、推論エンジンとAPIの2つのグループがあります。「自分のモデルを追加」で自分で用意したモデルを、「APIを追加」で翻訳に使うAPIを足せます（[自分のモデルを使う](../guide/custom-models#translation)）。

- TranslateGemmaのような翻訳のLLMは、GGUFのファイルを追加し、llama.cppのサーバー（Vulkan版）で動かします。サーバーはアプリに入っていないので、同意してから取得します。追加の前に、Gemmaの利用規約を確かめるチェックがあります。
- 以前の版で`translation-models`フォルダーに置いたモデルは、一覧に出なくなりました。「自分のモデルを追加」で追加し直してください。

## 確かめ方

「翻訳」をオンにして短い文を送ります。相手の言語に訳された文が会話ログに出ることを確かめます。

## 困ったとき

### 使えないエンジン

Google、Bing、Papagoのウェブ翻訳は使えません。本家VRCTの翻訳エンジン部分が公式のVRCTでだけ使えるライセンスになっているためです。

症状に合う対処は[困ったとき](../guide/troubleshooting)をご覧ください。
