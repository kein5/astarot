# 音声認識（ASR）とリアルタイム字幕

自分の声や、ほかのプレイヤーの声を聞き取って文字にします。設定は「設定」→「音声認識（ASR）」にあります。

文字にした発言はメイン画面の会話ログに出ます。VRの字幕オーバーレイにも出ます。「複数行」では自分と相手の発言を認識の途中から出し、「一行」ではゲーム音声の発言だけを、文が確定してから（翻訳を使うときは訳が付いてから）出します。

## 必要なもの

アプリに入っている音声認識（ASR）のサーバー（speech.cpp）を使うには、次の2つのモデルが必要です。

- 声を文字にする認識モデル
- 話している区間を見つけるSilero VAD

どちらもアプリには入っていないので、設定画面から取得するか、手元のファイルを指定します（[モデルの取得](../guide/models)、[自分のモデルを使う](../guide/custom-models#asr)）。

| モデル | 言語 | 容量 | ライセンス |
|---|---|---|---|
| Qwen3-ASR 0.6B / 1.7B | 30言語。言語を自動で判定 | 0.78 / 2.03 GiB | Apache-2.0 |
| ReazonSpeech v2 | 日本語だけ | 0.62 GiB | Apache-2.0 |
| Parakeet TDT-CTC 0.6B ja | 日本語だけ | 0.62 GiB | CC BY 4.0 |
| Parakeet TDT 0.6B v3 | ヨーロッパの25言語。言語を自動で判定（日本語は不可） | 1.17 GiB | CC BY 4.0 |
| Haas-ja v1.0 | 日本語だけ | 0.61 GiB | Apache-2.0 |
| Nemotron 3.5 Transcribe 30B-A4B | 40言語（大きなモデル） | 17.69 GiB | OpenMDW-1.1 |
| Silero VAD v6.2 · F32 | （話している区間を見つける） | 約1.2 MB | MIT |

容量はspeech.cppが既定で取得するファイルのものです。認識モデルはどれも取得するときにほかのファイルの種類（量子化）も選べます（[モデルの取得](../guide/models)）。

同梱サーバーが使う認識モデルは1つだけです。マイクの字幕とゲーム音声の字幕で、同じモデルを使います。

- 日本語以外を話す相手がいるなら、Qwen3-ASRを選んでください。
- 言語を「自動判定（auto）」にするには、Qwen3-ASRのように言語を判定できるモデルが必要です。

## 操作

### はじめて使う

1. 「設定」→「音声認識（ASR）」の「お使いのPCで動かす（speech.cpp）」にある「モデルとサーバー」を開き、「ASR + VAD」で認識モデルとSilero VADを取得します。

   ![「設定」→「音声認識（ASR）」の「モデルとサーバー」にある「ASR + VAD」の欄](/screenshots/ja/asr-models.webp)

2. 同じページの「詳細設定」にある「リアルタイム字幕」で、どの音を文字にするかを選びます。選んだものはすぐに保存されます。
   - 「マイクの字幕」は「マイク入力」で選んだマイクの声を文字にします。初めはシステムの既定の入力に従います。
   - 「ゲーム音声の字幕」は「ゲーム音声の出力先」から聞こえるほかのプレイヤーの声を文字にします。VRChatの音だけが出る出力デバイスを選んでください。ほかのアプリと共用の出力デバイスを選ぶと、そのアプリの音も文字になります。

   ![「設定」→「音声認識（ASR）」の画面](/screenshots/ja/transcription.webp)

3. メイン画面の「マイク入力」のスイッチでマイクの字幕を、「聞き取り」のスイッチでゲーム音声の字幕を始めたり止めたりします。同梱サーバーを選んでいれば、スイッチをオンにしたときにサーバーも起動します（「スイッチを入れたときに同梱ASRサーバーを起動する」がオンのとき。初めはオンです）。Windowsでは、「音声認識で使用するエンジン」で「ローカル（speech.cpp）」を選んでいるときに、このスイッチでリアルタイム字幕が動きます（[音声認識エンジンを選ぶ](#engines)）。

アプリを起動し直すと、字幕は止まった状態から始まります。

モデルがない、または選んだ言語をモデルが認識できないためにスイッチをオンにできないときは、スイッチのところのダイアログで理由と直し方を示します。おすすめのモデルの取得（取得する前に大きさを示します）、モデルが認識できる言語からの選択、言語を判定できないモデルではQwen3-ASRの取得から選べます。取得は同意したときだけ始まります。ダイアログから、その設定を直接開くこともできます。

[初期設定](../guide/first-setup)の画面からも、認識モデルとSilero VADを選んで取得できます。

#### 区切りと感度

「リアルタイム字幕」の「話し終わりとみなす無音の長さ」で、発話を確定するまでの無音の長さを選べます。既定は0.4秒です（0.5系までは0.5秒でした）。短くすると結果が早く出ますが、文の途中の間でも区切られやすくなり、1つの文が複数のメッセージに分かれることがあります。以前と同じにしたいときは「0.5秒」を選びます。

「発話を拾う感度（しきい値）」は、声と判定するのに要る確からしさです。周りがうるさいときは大きく、声が小さいときは小さくします。既定はサーバーに任せます。どちらも変えると両方の字幕が止まるので、保存してから始め直してください。

::: info 聞き取った相手の発言はVRChatへ送りません
ゲーム音声から文字にした相手の発言を、自分のチャットボックスへ送ったり、自分のマイクに流したりすることはありません。
:::

### 話した人を見分ける

ゲーム音声の字幕では、誰が話したのかを見分けられます。声の特徴から話した人を推定し、「話者A」「話者B」のように分けて表示します。

使うには、「モデルとサーバー」→「ASR + VAD」で話者分離モデルを取得して適用します。話者分離モデルは話した人を見分けるためのモデルです（Nemotron 3 Diarization、約106 MB、OpenMDW-1.1）。次にサーバーを起動したときから使われます。使わないときは「話者分離GGUFのパス（任意）」を空にします。

- 会話ログには「話者A」のように出ます。デスクトップの字幕オーバーレイでは文の前に「A」「B」が付き、人ごとに色が変わります。VRの字幕オーバーレイでは、「複数行」は「Receive」の後ろに、「一行」は文の上に出ます。
- 同じ人の発言が続くと、会話ログでは2行目から話者の表示を省き、ひとまとまりに見せます。
- 声の特徴から推定するので、名前までは分かりません。声が似ている人は、同じ人として扱われることがあります。
- 2人の発言の間が短いと、1つの字幕にまとまります。そのときは「話者A・B」と両方を出します。
- 「聞き取り」のスイッチをオンにするたびに、A、Bの割り当てはやり直しになります。前回の「話者A」と今回の「話者A」が同じ人とは限りません。
- 字幕の文が決まるまでの時間が、0.3秒ほど長くなります（RTX 3060 Tiで測った値）。
- GPUが必要です。CPUでは処理が間に合わないため、サーバーがCPUで動いているときは、モデルがあっても話した人を見分けません。
- マイクの字幕では話した人を見分けません。

#### 話した人に名前を付ける

会話ログの「話者A」を押すと、その場で名前を付けられます。名前は会話ログ、デスクトップの字幕オーバーレイ、VRの字幕オーバーレイ（一行と複数行）に出ます。「一行」で表示中の字幕は描き直さず、次の字幕から名前で出します。

名前は今の聞き取りの間だけ使い、保存しません。聞き取りを始め直すとA、Bの割り当てがやり直しになるので、名前も付け直します。VRパネルの会話ログでは名前を付けられません。

### 聞き取ってほしい言葉を登録する

聞き取ってほしい言葉と、その言葉をどう書くかを「用語辞書」に登録できます。VRChatでよく使う用語は初めから入っています。0.6.0からは、内蔵の用語の読みを変えたり、不要な語を外したり、元に戻したりできます。保存した変更はアプリを更新しても残ります。

ワールドの名前やフレンドの名前など、固有名詞を登録しておくと便利です。登録した語は音声認識のほかにも使います。

- 音声認識の結果はどのエンジンでも登録した書き方に直します。読みを登録すると、その読みで書かれた語も直します。
- 日本語の読み上げは登録した読みで読みます。
- AIの翻訳エンジン（OpenAI、Gemini、Groqなど）には、文に出てくる語を名前として伝えます。

読みが普段の言葉と同じだと、その言葉も書き換わります。読みはほかの言葉と重ならないものにしてください。

用語辞書は「詳細設定」の「リアルタイム字幕」にあります。「表記」と「読み」を入れて「用語を追加」を押します。たくさんの語は「ファイルから読み込む」で文字のファイルから読み込めます。読み込むと、今の辞書はファイルの内容に置き換わります。「ファイルに書き出す」で辞書をファイルに残せるので、別のPCに移すときや控えに使えます。変更はすぐに保存されます。自分で追加した用語と、読みを変えた内蔵の用語は、合わせて100語までです。

### 話した言葉を入力欄に貼り付ける

「設定」→「字幕とVR」の「音声タイピングモード」をオンにすると、文字にした発言をVRChatなどの入力欄へ貼り付けます。貼り付けにはクリップボードを使います。

- SteamVRが動いているときは、SteamVRで実行中のアプリ（VRChatなど）のウィンドウを前に出してから貼り付けます。
- SteamVRが動いていないときは、クリップボードへコピーするだけです。

Linuxで貼り付けられるのは、X11/XWaylandのウィンドウとして動いているアプリ（Protonで動くVRChatなど）です。KDEでは初めて貼り付けるときに、入力デバイスの操作を許可するかどうかをデスクトップが確認します。ネイティブのWaylandのウィンドウには貼り付けられないため、クリップボードへコピーするだけです。

### 音声認識エンジンを選ぶ（Windows） {#engines}

Windowsでは、メイン画面の「マイク入力」と「聞き取り」のスイッチで使う音声認識を、「設定」→「音声認識（ASR）」の「音声認識で使用するエンジン」で選びます。エンジンを選ぶ前に文字起こしをオンにすると、「音声認識エンジンを選ぶ」という画面が開きます。

エンジンは2つの系に分かれています。選ぶ欄でも系ごとに分けて並び、その下に同じ順で各系の設定があります。

- 「お使いのPCで動かす（speech.cpp）」：「ローカル（speech.cpp）」を選ぶと、お使いのPCのspeech.cppのサーバーで音声を文字にします。音声はお使いのPCの外に出ません。スイッチではリアルタイム字幕が動きます。認識モデルとSilero VADが必要です（[必要なもの](#必要なもの)）。モデルはこの系の「モデルとサーバー」で取得するか、自分のモデルのファイルを登録します（[自分のモデルを使う](../guide/custom-models#asr)）。登録したモデルには「自分のモデル」の印が付きます。
- 「API（クラウドや自分のサーバー）」：Groq Whisper、OpenAI Whisper、Deepgram、カスタムWhisperサーバーです。音声をそのサービスやサーバーへ送って文字にします。それぞれの行を開いてAPIキーを登録すると選べるようになります。カスタムWhisperサーバーは自分で用意するWhisperのサーバーで、「自分のサーバー」の印が付きます（[自分のモデルを使う](../guide/custom-models#whisper-server)）。起動したときに接続するのは、選んでいるエンジンとPCの中で動くサーバーだけです。ほかのエンジンのキーは選んだときに確かめます。

選んだエンジンから別のエンジンへ自動で切り替わることはありません。「ローカル（speech.cpp）」とほかのエンジンを切り替えると、動いていた「マイク入力」と「聞き取り」はオフになります。もう一度オンにすると、新しいエンジンで始まります。

ローカル（speech.cpp）で文字にできるのは、認識モデルが対応している言語です（Qwen3-ASRは30言語。Haas-ja、ReazonSpeech、Parakeet jaは日本語だけ）。ほかの言語はAPIのエンジンを使ってください。

「詳細設定」の「リアルタイム字幕」にある「ASRサーバー」の「同梱サーバー」と「外部サーバー」は、どちらもspeech.cppのサーバーです。外部サーバーはお使いのPCで自分で起動したspeech.cppのサーバーです。どちらを選んでも、音声はお使いのPCの外に出ません。

Linuxの「マイク入力」と「聞き取り」は、エンジンの選択にかかわらず、いつもリアルタイム字幕を使います。

## 確かめ方

有効にした入力に合わせて、マイクに話すかゲームの音を流します。聞き取った言葉が会話ログに出ることを確かめます。

## 困ったとき

### 以前の版でWhisperを使っていた場合 {#whisper}

アプリの中で動くWhisperは0.3.0でなくなりました。PCの中で音声を文字にするのは「ローカル（speech.cpp）」です。クラウドのWhisper（Groq Whisper、OpenAI Whisper、カスタムWhisperサーバー）は、これまでどおり使えます。

- 0.2以前の版で「音声認識で使用するエンジン」にWhisperを選んでいた場合、0.6.0からは選択が引き継がれず、エンジンは未選択になります。[最初の設定](../guide/first-setup)か「設定」→「音声認識（ASR）」で選び直してください。0.3から0.5までの版はWhisperの選択を「ローカル（speech.cpp）」へ切り替えて、お知らせを一度だけ出していました。
- Whisperのモデルの種類と処理デバイスの設定はなくなりました。認識のしきい値は「Whisperの認識結果のふるい分け」に残っていて、Groq Whisper、OpenAI Whisper（whisper-1）、カスタムWhisperサーバーで使います。

0.2以前の版が取得したWhisperのモデルはもう使いません。アプリは0.6.0からこのモデルの容量を数えたり消したりしません。空き容量を増やしたいときは、データのフォルダー（[インストール](../guide/install)の「設定とデータの場所」）の中の`weights`にある`whisper`フォルダーを消してください。

::: details 確かめた範囲
話した人を見分ける機能は、Windows 11で、読み上げの音声で作った2〜6人の会話を使って確かめました。実際の人の声では確かめていません。結果は開発者向けの[記録](https://github.com/kein5/astarot/blob/develop/docs/voice-stack/speaker-diarization-2026-11-13.md)にあります。
:::
