# 字幕とVR

VRの中やデスクトップの上で翻訳や字幕を見られます。設定は「設定」→「字幕とVR」にあります。

| 機能 | 使う場面 | 必要なもの |
|---|---|---|
| 字幕オーバーレイ | VRの視界に字幕を出す | SteamVR |
| デスクトップの字幕オーバーレイ | ヘッドセットを使わずに、VRChatの画面の上へ字幕を出す | WindowsかLinux（AppImage） |
| VR UI（実験的機能） | VRの中でASTAROTを操作する | SteamVR |

## 必要なもの

上の表で、使いたい表示に必要な環境を確かめます。

## 操作

### VRの視界に字幕を出す（字幕オーバーレイ）

メイン画面の右上の「クイック設定」で「字幕オーバーレイ」をオンにすると、VRの視界に翻訳や字幕を表示します。本家VRCTから引き継いだ機能です。

![「設定」→「字幕とVR」の画面](/screenshots/ja/vr.webp)

- 「一行」と「複数行」の表示を切り替えられます。「一行」はゲーム音声から聞き取った発言だけを、「複数行」は自分の発言やチャット読み取りの文も出します。
- 位置と回転、不透明度、サイズ、表示時間、フェードアウトの時間を調整できます。
- 字幕をHMD（ヘッドセット）・左手・右手のどれに付けて表示するかを、「表示するトラッカーの位置」で選びます。
- 「サンプルの文を字幕オーバーレイに送る」で見え方を確かめられます。
- 「翻訳後のメッセージのみ表示する」をオンにすると、原文を出さずに訳文だけを表示します。

### 画面の上に字幕を出す（デスクトップの字幕オーバーレイ）

「設定」→「字幕とVR」の「デスクトップの字幕オーバーレイ」で「デスクトップに字幕を表示する」をオンにします。会話ログに出た文をほかのウィンドウの上に重ねて表示します。

![画面の下に重なった字幕。相手の2人の発言に、話した人を表すAとBが付き、自分の発言は青で出ている](/screenshots/ja/captions-on-screen.webp)

背景は説明用の絵です。実際にはVRChatなど、画面に出ているものの上に重なります。

![「設定」→「字幕とVR」のデスクトップの字幕オーバーレイの欄](/screenshots/ja/desktop-captions.webp)

- 自分の発言（マイクや入力）は青、相手の発言（スピーカーやチャット読み取り）は紫の文字で出ます。会話ログと同じ色分けです。文の横の色の帯も、自分の発言は右、相手の発言は左に付きます。
- [話した人を見分ける機能](transcription#話した人を見分ける)を使っているときは、聞き取りの字幕の前に、話した人を表す「A」「B」などが付き、人ごとに色が変わります（紫、黄、緑、赤の順で、5人目からはこの色を繰り返します）。
- 字幕の上をクリックしても、その下のウィンドウを操作できます。キーボードの入力先も変わりません。
- 出す場所（画面の下・上）、文字の大きさ、表示時間、背景の濃さを変えられます。
- Ctrlキーを押しながら字幕をドラッグすると、好きな場所へ動かせます。Ctrlキーを押している間は字幕の範囲に枠が出ます。次に起動したときも動かした場所に出ます。
- 字幕の上にマウスを置いてCtrlキーを押しながら「+」か「-」を押すと、文字の大きさが変わります。ほかのときはCtrlキーと「+」「-」がそのままほかのアプリに届きます。
- 位置と文字の大きさは「字幕の位置と文字の大きさを初期に戻す」で元に戻せます。「字幕を出す場所」を選び直したときも、選んだ端に戻ります。
- 動かすまではASTAROTのメイン画面があるモニターに出ます。
- 「翻訳後のメッセージのみ表示する」はこの字幕にも当てはまります。
- 字幕と一緒に、入力が届いた先とかかった時間も出せます。[入力と出力](io-flow#デスクトップに表示する)を見てください。
- 排他フルスクリーン（画面を占有する全画面表示）で動くアプリの上には出ません。VRChatの全画面表示は枠なしのウィンドウなので、その上に出せます。
- LinuxではAppImageで起動したときに使えます。Waylandのデスクトップでも、アプリはXWaylandで動くので表示できます。tar.gzを起動するときは、`GDK_BACKEND=x11`を付けてください。付けずにネイティブのWaylandで動くと、この欄は出ません。

### VRの中で操作する（VR UI・実験的機能）

「設定」→「実験的機能」で「VR UIを表示する」をオンにすると、VRの中に、手首に付くランチャー（ボタンの並び）とウィンドウを表示します。VRの中から、機能のオンとオフ、ログの表示、言語、設定を操作できます。字幕オーバーレイとは別に使えます。本家VRCTから引き継いだ機能です。

VR UIは試験中の機能なので、ほかの試験中の機能と一緒に「実験的機能」のページにあります。前の版でオンにしていた場合は、そのままオンです。

ランチャーが見つからなくなったら、同じページの「ランチャーの位置と大きさを初期に戻す」を押してください。左手首に戻ります。このボタンはVR UIをオンにしている間だけ出ます。

::: details 確かめた範囲
- Linuxのデスクトップの字幕オーバーレイは、試験用のX11の画面（ウィンドウマネージャーなし）で、字幕のウィンドウがウィンドウマネージャーの管理を受けずに表示され、送った文が出ることを、自動試験で確かめました。KDE PlasmaでVRChatのフルスクリーンの上に出ること、NVIDIAのGPUで透明な窓が描かれることは、まだ確かめていません。
- デスクトップの字幕オーバーレイはWindows 11でVRChat（ウィンドウ表示とフルスクリーン）の上に出ることを確かめました。使ったのは試験用の文です。ゲーム音声から出た字幕はVRChatを起動せずに確かめました。マイクの字幕では確かめていません。
- LinuxのVR UIはSteamVRの代わりになる試験用の仕組みで確かめただけです。実際のヘッドセットでは確かめていません。
- 字幕オーバーレイとVR UIは、ASTAROTではまだ詳しく確かめていません。
:::

## 確かめ方

VRの字幕はサンプル文を送って確認します。デスクトップの字幕は、会話ログの新しい行がほかのウィンドウの上に出ることを確かめます。

## 困ったとき

字幕が出ないときは、使う字幕のオーバーレイが有効か、対応する環境で使っているかを確かめます。
