# 自分のモデルを使う

設定画面から取得できる既定のモデルのほかに、自分で用意したモデルも使えます。自分で学習したモデル、ほかの場所で配布されているモデル、購入したモデルです。

使えるかどうかは機能によって違います。

| 機能 | 使えるもの | 指定する所 |
|---|---|---|
| テキスト読み上げ（TTS） | <Term tip="AIのモデルを1つのファイルに収める形式です。speech.cppが読み込みます。拡張子は.ggufです。">GGUF</Term>のモデルと、声のGGUF（任意）。またはお使いのPCで動かすサーバー | 「テキスト読み上げ（TTS）」→「モデルとサーバー」 |
| 音声認識（ASR） | GGUF の認識モデル、VAD、話者分離モデル（任意）。またはお使いの PC で動かすサーバー | 「音声認識（ASR）」→「お使いのPCで動かす（speech.cpp）」→「モデルとサーバー」→「ASR + VAD」 |
| Whisper | 自分の Whisper サーバー（OpenAI 互換） | 「音声認識（ASR）」→「API（クラウドや自分のサーバー）」→「カスタムWhisperサーバー」 |
| ボイスチェンジャー（RVC） | `.pth` のモデルと `.index`（任意） | 「ボイスチェンジャー（RVC）」 |
| 翻訳 | 対応するローカルモデルのフォルダー、TranslateGemmaのGGUFファイル、自分のサーバーに入れたモデル | 「設定」→「翻訳」 |
| チャット読み取り（OCR） | 使えません | — |

設定画面の各モデルの欄にある「自分のモデルを使う方法」を押すと、このページの該当する節が開きます。

ファイルやフォルダーの場所は、入力するか貼り付けるほか、欄の横の「ファイルを選択」か「フォルダーを選択」を押して、お使いのPCから選べます。選択画面には、その欄が受け付ける種類のファイルだけが出ます。選んだ場所は、入力したときと同じように欄に入ります。選択をやめた場合は何も変わりません。

::: warning アプリは利用条件を確かめません
設定画面から取得するモデルは、提供元、ライセンス、容量を示して同意を得てから取得します。自分で指定したファイルについては、アプリは利用条件を確かめません。使ってよいかは自分で確かめてください（[購入したモデルと配布されているモデル](#bought-models)）。
:::

## テキスト読み上げ（TTS） {#tts}

### 使えるファイル

- 同梱の speech.cpp が読み込める、読み上げ用の GGUF のモデル。例は Irodori-TTS と Qwen3-TTS です。
- 声の GGUF（任意）。参照の録音から作った声のファイルで、Irodori-TTS で使えます。作り方は [speech.cpp](https://github.com/nyosegawa/speech.cpp) の `speech voice` の説明にあります。

### 指定する

1. 「設定」→「テキスト読み上げ（TTS）」の下のほうにある「モデルとサーバー」を開きます。
2. 「日本語TTS」か「多言語TTS」の「モデルGGUFのパス」にファイルの場所を入れます。日本語の読み上げには「日本語TTS」を、ほかの言語には「多言語TTS」を使います。
3. 声の GGUF を使うときは、「声GGUFのパス（任意）」に場所を入れます。
4. Enterを押すか欄を離れると、保存されます。
5. 声の GGUF を使うときは、上の「日本語の声名」か「他言語の声名」に `custom` と入れて保存します。
6. メイン画面で「テキスト読み上げ（TTS）」をオンにします。サーバーはこのとき起動します。

### 自分で動かすサーバーを使う

ASTAROTと同じPCでspeech.cppのサーバーを自分で動かしているときは、「日本語のサーバー」などで「外部サーバー」を選び、URLを入れます。URLに使えるのは`127.0.0.1`、`localhost`、`::1`だけです。

### うまくいかないとき

| 出るメッセージ | 確かめること |
|---|---|
| この言語の同梱TTSサーバーに使えるモデルがありません | ファイルの場所が正しいか。拡張子が `.gguf` か |
| このモデルはこのサーバーの用途（読み上げ・認識）に合いません | 認識用のモデルを読み上げの欄に入れていないか |

声名を間違えると、読み上げるときに番号つきのエラーが出ます。声の GGUF を使うときは、声名が `custom` になっているかを確かめてください。

## 音声認識（ASR） {#asr}

### 使えるファイル

- 同梱の speech.cpp が読み込める、認識用の GGUF のモデル。例は Qwen3-ASR と Haas-ja です。
- VAD（話している区間を見つけるモデル）の GGUF。認識モデルと一緒に、必ず指定します。
- 話者分離モデル（話した人を見分けるモデル）の GGUF（任意）。

### 指定する

1. 「設定」→「音声認識（ASR）」の「お使いのPCで動かす（speech.cpp）」にある「モデルとサーバー」を開き、「ASR + VAD」を見ます。
2. 「モデルGGUFのパス」と「VAD GGUFのパス」にファイルの場所を入れます。話した人を見分けるときは、「話者分離GGUFのパス（任意）」にも入れます。
3. Enterを押すか欄を離れると、保存されます。
4. メイン画面で「マイク入力」か「聞き取り」をオンにします。

お使いのPCで自分の認識サーバーを動かしているときは、「リアルタイム字幕」の「ASRサーバー」で外部のサーバーを選び、URLを入れます。

### うまくいかないとき

| 出るメッセージ | 確かめること |
|---|---|
| 同梱ASRサーバーのモデルファイルが見つからないか、GGUFではありません | 認識モデルと VAD の場所が正しいか。拡張子が `.gguf` か |
| このモデルはこのサーバーの用途（読み上げ・認識）に合いません | 読み上げ用のモデルを認識の欄に入れていないか |
| このASRモデルは選んだ言語を認識できません | モデルが話す言語に対応しているか |

## Whisper のサーバー {#whisper-server}

アプリの中では Whisper は動きません（[以前の版でWhisperを使っていた場合](../features/transcription#whisper)）。Whisper のモデルを使いたいときは、OpenAI 互換の Whisper のサーバー（`/v1/audio/transcriptions`）を自分で動かし、そこにつなぎます。

1. 「設定」→「音声認識（ASR）」の「API（クラウドや自分のサーバー）」で「カスタムWhisperサーバー」を開きます。「自分のサーバー」の印が付いている行です。
2. URL とキーを入れて保存します。キーが必要ないサーバーでも、キーの欄には何か文字を入れます。キーが空のままだと URL だけを覚え、つながるかの確認もモデルの一覧の読み込みもしません。
   保存すると、サーバーにつながるかを確かめてモデルの一覧を読みます。
3. モデルを選び、上の「音声認識で使用するエンジン」で「カスタムWhisperサーバー」を選びます。

URLはHTTPSにします。HTTPを使えるのは、ASTAROTを動かしているPC（localhost）かローカルネットワークのIPアドレスのときだけです。

## ボイスチェンジャー（RVC） {#rvc}

### 使えるファイル

- RVC のモデル（`.pth`）。v1 か v2 で、サンプリングレートが 32k・40k・48k のものです。
- 検索インデックス（`.index`）。任意です。「検索結果の混合率」を 0 より大きくするときは必要です。

RVC を動かすには、実行環境も必要です。実行環境は設定画面から取得できます（[ボイスチェンジャー](../features/voice-conversion)）。

### 指定する

1. 「設定」→「ボイスチェンジャー（RVC）」を開きます。
2. 下の「モデルと実行環境」を開き、「利用許可のあるRVCモデル（.pth）」にモデルの場所を入れます。インデックスがあれば「RVC検索インデックス（.index、省略可）」にも入れます。
3. Enterを押すか欄を離れると、保存されます。
4. メイン画面で「ボイスチェンジャー（RVC）」をオンにします。

### うまくいかないとき

| 出るメッセージ | 確かめること |
|---|---|
| このモデルの形式には対応していません | モデルが v1 か v2 で、32k・40k・48k のものか |
| RVCモデル（.pth）か検索インデックス（.index）が見つかりません | ファイルの場所が正しいか |
| 検索インデックス（.index）を読み込めません | 別の `.index` を選ぶか、「検索結果の混合率」を 0 にする |
| モデルか基礎モデル（HuBERT）の中身が足りないか、形が合いません | モデルのファイルが壊れていないか。実行環境を取得し直す |

## Seed-VC {#seed-vc}

Seed-VCは0.5.0で外しました。参照の WAV で声を変える使い方はできなくなりました。自分のモデルで声を変えるときは、上の[ボイスチェンジャー（RVC）](#rvc)を使います。

## 翻訳 {#translation}

「設定」→「翻訳」→「翻訳のカタログ」で、対応するM2M100やNLLB-200のモデルを追加できます。`manifest.json` が入ったフォルダーを指定します。TranslateGemmaを使う場合は、利用条件を確認してllama.cppの実行環境を取得し、自分で用意したGGUFファイルを追加します。使い始めるときにモデルを選びます。

LM Studio、Ollama、OpenAI互換サーバーで動かすモデルを使うときは、そのサーバーにつなぎます。

1. 使うサーバーにモデルを入れて起動します。
2. 「設定」→「翻訳」→「詳細設定」→「ローカルLLM・互換サーバー」で、使うサーバーの「接続確認」を押します。
3. モデルを選び、メイン画面の「翻訳エンジン」でそのサーバーを選びます。

詳しくは[翻訳](../features/translation#ローカルllmと互換サーバーを使う)を見てください。

## 購入したモデルと配布されているモデル {#bought-models}

自分で学習していないモデルは、使う前に提供元の利用規約を読んでください。とくに次の点を確かめます。

- VRChat の中で使ってよいか
- 配信や録画で使ってよいか
- クレジットの表示が必要か。必要なら、どこに何を書くか
- 改変してよいか
- 再配布してよいか

ほかにも気をつけることがあります。

- 実在する人の声を使ったモデルや参照の録音を使うには、その人の許可が必要です。
- モデルのファイルをほかの人に渡すのは、規約で許されているときだけにしてください。
- 購入したときのライセンスの文面は、手元に残しておくと後で確かめられます。

## 使えないもの

チャット読み取り（OCR）の認識モデルとチャットボックス検出器は、設定画面から取得したものだけを使います。ファイルの容量とハッシュが一致したときだけ読み込むので、自分のモデルには置き換えられません。
