# 動作環境と推奨スペック

必要なPCの性能は使う機能によって大きく変わります。文字の翻訳と相手の声の字幕だけなら、GPUは必要ありません。読み上げ、ボイスチェンジャー、VRChatを同じPCで同時に使うなら、メモリとGPUに余裕が必要です。

このページの値は試験用のPC 1台で測った値と、モデルの大きさから出した目安です。動作を保証するものではありません。測ったPCの構成はページの最後にあります。

## 対応するOS

| OS | 条件 |
|---|---|
| Windows | 64ビットのWindows 11で確かめています。Windows 10では確かめていません。WebView2 Runtimeが必要です。入っていなければ、インストーラーが取得します。 |
| Linux | x86-64のPCで、<Term tip="多くのLinuxのアプリが使う基本のライブラリ（GNU Cライブラリ）です。版はldd --versionで確かめられます。">glibc</Term> 2.39以降、GTK 3、WebKitGTK 4.1が必要です。debとrpmは、Ubuntu 24.04、Debian 13、Fedora 44に入れられることを確かめています。実際のモデルを使った動作は、0.5より前の版をCachyOS（KDE Plasma、Wayland）で動かして確かめました。 |

macOS版はありません。配布形式と機能ごとに、どこまで確かめたかは[対応環境と検証の範囲](support)にあります。

Linuxでアプリが管理する音声経路を使うには、Linux 6.9以降、PipeWire、WirePlumber 0.5が必要です（[Linuxの音声経路](linux-audio)）。デスクトップの字幕オーバーレイはX11かXWaylandで動きます。

## メモリ

| 使い方 | アプリが使ったメモリ（測った値） | PCのメモリの目安 |
|---|---|---|
| 翻訳と相手の声の字幕（以前の版で、音声認識はWhisper tiny、どちらもCPU） | 約3.6 GB | 16 GB以上 |
| 読み上げ、字幕、ボイスチェンジャー（RVC）、翻訳、VRの字幕を同時に（0.3以前のRVCの実行環境で） | 約11.5〜13.1 GB | 32 GB以上 |

「アプリが使ったメモリ」は、ASTAROTのプロセスのプライベートメモリの合計を、30分〜2時間の運転で測った値です。「PCのメモリの目安」はこの値にOSとVRChatの分を足して出しました。VRChat自身のメモリは測っていません。

1行目は、アプリの中で動くWhisperがあった以前の版で測った値です。いまの版では、手元で動く音声認識はローカル（speech.cpp）が行います。その構成では測り直していません。

2行目は0.3以前のRVCの実行環境で測った値です。0.4.0ではRVCの変換をアプリに入っている処理で行い、実行環境も変わりました。0.4.0の構成では測り直していません。

## GPU

| 機能 | 必要なGPU |
|---|---|
| 翻訳、チャット読み取り | 必要ありません。CPUで動きます |
| 読み上げ、ローカルの音声認識とリアルタイム字幕、話した人を見分ける機能（アプリに入っているspeech.cpp） | <Term tip="GPUで描画や計算をするための仕組みです。NVIDIA、AMD、IntelのGPUのドライバーが対応しています。">Vulkan</Term>に対応したNVIDIA、AMD、Intelの独立GPU。内蔵GPUだけのPCでは「自動」でCPUを使って読み上げや字幕を動かせます。話者の識別には対応するGPUが必要です |
| ボイスチェンジャー（RVC） | 音声を遅れずに変換できるCPU、またはCUDA対応のNVIDIAのGPU（次の節）。Windowsでは0.6.0から、DirectMLの実行環境を取得するとDirectX 12対応のGPUも使えます |

## NVIDIAのGPUでRVCを使うとき

0.4.0から、RVCをCUDAで変換するにはNVIDIAのドライバー580以降が必要です。RVCが使うCUDAの版が13になったためです。CUDAを使えない場合は、CPUでも変換できます。声の遅れは約0.2秒から約1.3秒に増え、CPUの性能によっては変換が追いつかずに止まります。

| | 条件 |
|---|---|
| ドライバー | 580以降。WindowsとLinuxのどちらも同じです |
| CUDA 13で変換できるGPU | GeForce GTX 16シリーズ、RTX 20シリーズとそれより新しいGPU |
| CUDA 13の対象外のGPU | GeForce GTX 10シリーズとそれより古いGPU（GTX 1080 Ti、GTX 1060、GTX 900シリーズなど）。同じ世代までの業務用のGPU（Quadro PシリーズやTITAN Vなど）も対象外です |

ドライバーの版はNVIDIAコントロールパネルの「システム情報」か、コマンド`nvidia-smi`で確かめられます。0.3以前のRVCはドライバーがCUDA 12.8に対応していれば動いたので、ドライバーを更新しないまま0.4.0にすると、それまでGPUで動いていたRVCがCPUで動くことがあります。GPUで使い続けるには、ドライバーを580以降に更新してください。

読み上げ、音声認識、字幕に使うspeech.cppはCUDAではなくVulkanで動くので、この条件の影響を受けません。

## GPUのメモリ

読み上げのモデルが使うGPUメモリの目安は次のとおりです。詳しくは[モデルの取得](models#gpuとメモリの目安)にあります。

| モデル | GPUメモリの目安 |
|---|---|
| Irodori-TTS v4.1 Small MF · F16（日本語） | 約2.3 GB |
| Irodori-TTS v4.1 Small MF · Q8_0（日本語、軽量） | 約1.6 GB |
| Qwen3-TTS 0.6B · Q8_0（ほかの言語） | 約1.3 GB |
| Qwen3-TTS 0.6B · Q5_K（ほかの言語、軽量） | 約1.0 GB |

GeForce RTX 3060 Ti（8 GB）で読み上げ、字幕、RVC（0.3以前の実行環境）を同時に動かしたとき、GPU全体の使用量は約4.8 GBでした。VRChat（デスクトップ表示）も同じGPUで動かしたときは約6.1 GBで、いちばん多いときは約7.2 GBでした。すべての機能をVRChatと同じGPUで使うなら、GPUメモリは8 GB以上が目安です。VRのヘッドセットでVRChatを動かしたときの値は測っていません。

## CPU

確かめたCPUはIntel Core i7-1255U（ノートPC向け、10コア12スレッド）だけです。必要な最低限のCPUは決めていません。

| 使い方 | CPU使用率（1論理コアを100%とした値） |
|---|---|
| 翻訳と相手の声の字幕（以前の版で、音声認識はWhisper tiny、どちらもCPU） | 21〜34% |
| 読み上げ、字幕、RVCをGPUで動かし、翻訳をCPUで（0.3以前のRVCの実行環境で） | 63〜137% |

## ストレージの空き容量

| もの | 大きさ |
|---|---|
| アプリ（Windows） | ZIPが約36 MB、展開すると約0.1 GB |
| アプリ（Linux） | ダウンロードが約0.5 GB、展開すると約1.3 GB |
| 翻訳のモデル（1つ） | 0.4〜3.3 GB |
| 読み上げのモデル（日本語とほかの言語で1つずつ） | 1つ0.8〜1.8 GiB |
| 音声認識のモデル | 0.6〜0.8 GiB |
| RVCの実行環境 | 空きがWindowsで約2.7 GB、Linuxで約3.3 GB必要（NVIDIAのドライバーがないPCのCPU用は約0.8 GB） |

すべての機能をそろえるなら、Windowsでは約11 GBの空きが目安です。モデルの一覧と大きさは[モデルの取得](models)にあります。
