# 対応環境と検証の範囲

ASTAROTがどの環境に対応していて、どこまで確かめてあるかをまとめたページです。0.5.2の時点の内容です（2026-11-18）。

自動の試験が通っていても、実際のPCで動くことを確かめたとは限りません。このページでは対応の扱いと確かめ方を分けて書きます。確かめた記録がないものは「未検証」と書きます。必要なメモリ、GPU、空き容量は[動作環境と推奨スペック](requirements)にあります。

## 表の見かた

対応の扱いは次の3つです。

| 扱い | 意味 |
|---|---|
| 正式サポート | 配布物を出していて、不具合を直す対象にしている環境です |
| ベストエフォート | 動くことを想定していますが、確かめていないか、確かめた範囲が狭い環境です。不具合の報告は受け付けますが、直せないことがあります |
| 未対応 | 配布物がない環境です |

確かめ方は次の3つです。

| 確かめ方 | 意味 |
|---|---|
| CI | GitHubのサーバーで自動の試験を流して確かめました。実際の音声機器、GPU、VRChat、ヘッドセットは使っていません |
| 実機 | 実際のPCで動かして確かめ、記録が残っています。確かめた版を添えます |
| 未検証 | どちらでも確かめた記録がありません |

0.5.0でアプリの中の処理を作り直しました。そのため、0.5より前の版で確かめたことは「0.5より前の版で確認」と分けて書き、0.5系では確かめていないものとして扱います。

## OSと配布形式

| OS | 配布形式 | 扱い | CI | 実機 |
|---|---|---|---|---|
| Windows 11（x64） | インストーラー（`VRCT-VOX_setup.exe`） | 正式サポート | 中身の検査。インストール、更新、失敗したときの巻き戻しは、軽いダミーの中身で試験 | 0.5.1で、0.5.0からの更新と更新後の起動を確認。新規のインストールは未検証 |
| Windows 11（x64） | ZIP（`VRCT-VOX.zip`） | 正式サポート | 中身の検査 | 0.5.1で、展開して起動することを確認 |
| Windows 11（x64） | CUDA版のZIP（0.5までのリリースだけ） | 0.5で終わり | なし | 0.5.0から中身はZIPと同じです。次の版からは作らず、どのPCも上のZIPかインストーラーを使います |
| Windows 10（x64） | インストーラーとZIP | ベストエフォート | なし | 未検証 |
| Ubuntu 24.04、Debian 13（x64） | deb | 正式サポート | まっさらな環境に入れて、必要なライブラリがそろうこと、同梱の音声エンジンが起動すること、削除で何も残らないことを確認。画面は開いていません | 未検証 |
| Fedora 44（x64） | rpm | 正式サポート | debと同じ | 未検証 |
| Linux（x64、glibc 2.39以降） | AppImage | 正式サポート | Ubuntu 24.04の仮想の画面（X11）で、展開して起動する方式での起動、描画、設定画面の操作、終了を確認。FUSEで起動する方式は試していません | 0.5.2で、FUSEと展開の両方式での起動、描画、設定画面の操作、終了を確認（CachyOS、KDE PlasmaのWayland） |
| Linux（x64、glibc 2.39以降） | tar.gz | ベストエフォート | Ubuntu 24.04の仮想の画面（X11）で、読み取り専用の場所に置いての起動、描画、設定画面の操作、終了を確認 | 0.5系は未検証 |
| 上に挙げていないLinux（x64） | deb、rpm、AppImage、tar.gz | ベストエフォート | なし | 未検証 |
| WindowsとLinuxのARM64 | なし | 未対応 | なし | なし |
| macOS | なし | 未対応 | なし | なし |

Windowsの実機の記録はどれもWindows 11のInsider Preview版（0.5.1はbuild 26320）で取ったものです。一般向けに配信されているWindows 11では確かめていません。

## Linuxのデスクトップ環境

| 環境 | 実機 | 気をつけること |
|---|---|---|
| KDE Plasma（Wayland） | 0.5.2で、AppImageの起動、描画、設定画面の操作を確認 | アプリの画面はXWaylandで動きます。ホットキーはデスクトップのポータル（XDG Desktop Portal）を通して登録します |
| GNOMEなど、ほかのデスクトップ | 未検証 | トレイを表示できないデスクトップでは、メイン画面を閉じるとアプリが終了します |
| X11のセッション | 未検証 | CIの試験はウィンドウマネージャーのないX11の仮想の画面で動かしています |

デスクトップの字幕オーバーレイはX11かXWaylandで動きます。tar.gzを起動するときは`GDK_BACKEND=x11`を付けてください。NVIDIAのGPUのPCでは、AppImageは描画の不具合を避けるために窓を透明にしません。

## 必要なもの

| OS | 必要なもの |
|---|---|
| Windows | WebView2 Runtime（なければインストーラーが取得します）。VRChatへ声を届けるには仮想ケーブル（[Windowsの音声経路](windows-audio)）。RVCをGPUで使うにはNVIDIAのドライバー580以降 |
| Linux | glibc 2.39以降、GTK 3、WebKitGTK 4.1、PipeWire。GPUで推論するにはVulkanのローダーとドライバー。AppImageはFUSE（なければ`APPIMAGE_EXTRACT_AND_RUN=1`）。アプリが管理する音声経路にはLinux 6.9以降とWirePlumber 0.5（[Linuxの音声経路](linux-audio)） |

## 機能ごとの対応

WindowsとLinuxの欄は実機で確かめた範囲です。どちらの版も、機能は同じものを配布しています。

| 機能 | Windows | Linux | CIで確かめていること |
|---|---|---|---|
| 起動、メイン画面、設定画面 | 0.5.1で確認 | 0.5.2で、AppImageの起動、メイン画面、設定画面を確認 | Linuxのtar.gzとAppImageの起動と設定画面の操作。両方のOSで画面の部品の試験とビルド。Windowsで画面を開く試験はありません |
| マイクの入力、スピーカーへの出力 | 0.5系は未検証。0.5より前の版で、内蔵のマイクで確認 | 未検証 | 機器を使わない試験だけ |
| 仮想マイク | 0.5系は未検証。アプリは仮想マイクを作れないので、仮想ケーブルを別に入れます | 0.5系は未検証。0.5より前の版で、VRChatのマイクに届くことを確認。アプリがPipeWireで仮想マイクを作ります | Linuxは試験用のPipeWireで音声の補助プログラムを試験。Windowsはなし |
| 翻訳 | 未検証。ローカル翻訳のモデルはまだ配布していません | 未検証。Windowsと同じです | 機器とネットワークを使わない試験だけ |
| 音声認識（ASR）とリアルタイム字幕 | 0.5系は未検証。0.5より前の版で確認 | 0.5系は未検証。0.5より前の版で確認 | モデルを使わない試験だけ |
| テキスト読み上げ（TTS） | 0.5系は未検証。0.5より前の版で確認 | 0.5系は未検証。0.5より前の版で確認 | モデルを使わない試験だけ |
| ボイスチェンジャー（RVC） | 0.5系は未検証。0.5より前の版で確認 | 0.5系は未検証。0.5より前の版で確認 | モデルを使わない試験だけ |
| チャット読み取り（OCR） | 0.5.1で、範囲を決めて読む方式を試験用のウィンドウで確認。実際のVRChatでの吹き出しの検出は未検証 | 0.5系は未検証。VRChatのウィンドウはXWaylandを通して読みます。Waylandのウィンドウは共有すると読めます | モデルを使わない試験だけ |
| VRChatへのメッセージ送信（OSC） | 0.5系は未検証。0.5より前の版でVRChatの検出を確認 | 未検証 | 機器を使わない試験だけ |
| VRの字幕オーバーレイとVR UI | 0.5系は未検証。0.5より前の版で、ヘッドセットのないSteamVRで確認 | 未検証。0.5より前の版で、SteamVRの代わりの試験用の仕組みでだけ確認 | 偽のSteamVRを使う試験。実際のヘッドセットではどちらのOSも確かめていません |
| デスクトップの字幕オーバーレイ | 0.5系は未検証。0.5より前の版でVRChatの上に出ることを確認 | 未検証 | 設定画面の部品の試験だけ |
| ホットキー | 0.5系は未検証。0.5より前の版で、プログラムから送ったキーで確認 | 未検証 | 設定画面の部品の試験だけ |
| アプリの中の更新 | 0.5.1で、インストーラー版の0.5.0からの更新を確認 | AppImageは未検証。debとrpmはパッケージマネージャーで更新します | Windowsのインストーラーの更新と巻き戻しを、軽いダミーの中身で試験 |

更新のしかたは配布形式で変わります。インストーラー版とAppImage版はアプリの中で更新できます。ZIPとtar.gzは新しい版があることだけを知らせます。debとrpmはアプリが更新を確認しません（[インストール](install#更新)）。

## 不具合を知らせるとき

[Issues](https://github.com/kein5/astarot/issues)で、OSとその版、配布形式、ASTAROTの版を書いてください。Linuxではディストリビューション、デスクトップ環境、WaylandかX11かも書いてください。未検証の環境で動いたという報告も、この表を直すのに役立ちます。

## GPUの動作の報告

開発者の手元にないGPU、とくにAMDのGPUで読み上げと音声認識が動くかの報告を集めています。0.6.0からアプリの中で計測して報告できます。

1. 読み上げと音声認識のモデルを取得しておきます（[モデルの取得](models)）。
2. 「設定」→「詳細設定」→「GPUの動作の報告」で「確かめる」を押します。決まった短い文をCPUと各GPUで処理します。数分かかることがあります。マイク、スピーカー、VRChatは使いません。
3. 終わると機器ごとの結果と送る内容の全文が出ます。中身を確かめてから「GitHubで報告する」を押すと、内容を入れた状態で報告の画面が開きます。送るにはGitHubのアカウントが要ります。

結果に入るのはアプリとOSのバージョン、CPUとGPUの名前、メモリの量、GPUのドライバのバージョン、モデルの名前、計った時間とずれだけです。ユーザー名、ファイルの場所、読み上げた文や聞き取った文は入りません。アプリは何も送りません。送るかどうかは全文を見てから選べます。

このページの根拠は開発者向けの[対応環境の検証の記録](https://github.com/kein5/astarot/blob/develop/docs/voice-stack/platform-verification.md)にあります。
