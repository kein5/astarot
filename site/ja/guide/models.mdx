# モデルの取得

ASTAROTの配布物にはテキスト読み上げ・音声認識・ボイスチェンジャー・文字認識のモデルを入れていません。使うモデルは設定画面から取得するか、手元のファイルを指定します。手元のファイルの使い方は[自分のモデルを使う](./custom-models)にあります。

## 取得の流れ

1. 各ページの「既定モデルのダウンロード」で「取得内容を確認」を押します。「テキスト読み上げ（TTS）」と「音声認識（ASR）」では「モデルとサーバー」の中にあります。
2. 提供元、モデル名、正確な容量、利用条件へのリンク、保存先を確かめます。
3. 同意のチェックを入れて「同意してダウンロード」を押します。取得中は取り消せます。
4. 取得と確認が終わったら「モデルパスを適用」を押します。そのモデルを使うサーバーや機能は、先に止めておいてください。

![モデルの取得と利用条件を確かめる画面](/screenshots/ja/model-consent.webp)

取得しただけ、適用しただけでは、サーバーの起動、読み上げ、マイクの使用は始まりません。

読み上げのモデルはサーバーを起動したあと、使用中のモデルのカードの「試聴する」で声を自分だけで聞けます（[声を試聴する](../features/tts#声を試聴する)）。

::: info ファイルの確認
取得したファイルは容量とSHA-256を確かめてから使います。取得先はあらかじめ決めたHugging Faceのリポジトリと、その特定のバージョンだけです。
:::

日本語の読み上げは、最初の音がいちばん早く出るSmall MFが標準です。MFの付かないSmallとLargeは、最初の音が出るまで長く待ちます。Largeは文章を読む部分がGoogleのGemmaに由来するので、[Gemmaの利用規約](https://ai.google.dev/gemma/terms)と禁止用途のポリシーに従います。

音声認識のモデルはアプリに入っているspeech.cppが扱うものをすべて選べます。表の容量はspeech.cppが既定で取得するファイルのものです。「ファイルの種類（量子化）」ではほかの種類（Q4_Kなど）も選べます。小さい種類ほど容量とメモリーが少なく済みますが、誤りが少し増えることがあります。

翻訳のモデルは「設定」→「翻訳」で取得します（[翻訳](../features/translation)）。一覧にはダウンロードできるモデルが並び、「取得内容を確認」を押すと、提供元・ライセンス・容量を確かめる画面が開きます。同意のチェックを入れるまで取得は始まりません。

以前の版にあったWhisperのモデルは、もう取得できません。手元で動く音声認識は、上の表の音声認識のモデルとSilero VADを使います（[以前の版でWhisperを使っていた場合](../features/transcription#whisper)）。PCに残っている古いWhisperのモデルは、「設定」→「音声認識（ASR）」の「古いWhisperモデル」で削除できます。

## GPUとメモリの目安

読み上げのページではGPUの名前とメモリの合計・空きを表示し、空きに合わせて標準か軽量のモデルを勧めます。これは目安です。メモリを予約するものでも、動作を保証するものでもありません。VRChatなどと同時に使うときは余裕を多めに見てください。

### 動作確認の記録

読み上げとボイスチェンジャーのモデルをどこまで確かめたかの記録です。設定画面のモデルのカードの「必要メモリと動作確認」（メモリの目安がないモデルは「動作確認」）でも、同じ記録を見られます。

| モデル | 動作確認したGPU |

| Irodori-TTS v4.1 Small MF · F16 | NVIDIA GeForce RTX 4080 SUPER |
| Irodori-TTS v4.1 Small MF · Q8_0 | NVIDIA GeForce RTX 4080 SUPER |
| Irodori-TTS v4.1 Small · F16 | 動作確認待ち |
| Irodori-TTS v4 Large · Q8_0 | 動作確認待ち |
| Qwen3-TTS 12Hz 0.6B CustomVoice · Q8_0 | NVIDIA GeForce RTX 4080 SUPER |

::: info 確かめた範囲（読み上げ）
Linux（speech.cpp 0.9.0、Vulkan）で短い文を読み上げられることを確かめました。ほかのGPU、長い文、音質はまだ確かめていません。
:::

お使いのGPUが表のGPUと違うときは、カードにそのことが出ます。そのときに勧めるモデルはメモリの量だけで決めたものです。

ボイスチェンジャーのモデル（Saisho Utane · RVC v2）には、メモリの目安と、動作確認したGPUの記録がありません。確かめた範囲は次のとおりです。

::: info 確かめた範囲（ボイスチェンジャー）
Linux（AppImage）で、声を変換して流せることと、ミュート中は音を出さないことを確かめました。音質、Windows、ほかのGPUはまだ確かめていません。
:::

## 使えるGPU

| 機能 | GPU |
|---|---|
| 読み上げ、リアルタイム字幕、話した人の見分け（アプリに入っているspeech.cpp） | AMD、Intel、NVIDIA（Vulkan） |
| ローカルの翻訳 | CUDA対応のNVIDIAのGPU。WindowsではDirectX 12対応のGPUもDirectMLで使えます。どちらも実行環境の取得が要ります |
| ボイスチェンジャー（RVC） | CUDA対応のNVIDIAのGPU。Windowsでは0.6.0からDirectX 12対応のGPUもDirectMLで使えます。変換が間に合うPCではCPUでも動きます（[ボイスチェンジャー](../features/voice-conversion)） |
| チャット読み取り | CPUで動きます |

「モデルとサーバー」で推論デバイスを「自動」にすると、計算に使える独立GPUのうち、メモリが最も多いものを選びます。該当するGPUがなければCPUを使います。独立GPUは名前で指定することもできます。

AMDやIntelのGPUで翻訳したいときは、[ローカルLLM](../features/translation#ローカルllmと互換サーバーを使う)を使えます。OllamaやLM StudioはAMDとIntelのGPUにも対応しています。

## 保存先

取得したモデルは設定ファイル（`config.json`）と同じフォルダーの`downloaded_models`に保存します。Linuxでは<CopyText>\~/.config/astarot/downloaded_models</CopyText>（0.5.xまでは`vrct-vox`のフォルダーの中）、Windowsではアプリを入れたフォルダーの`downloaded_models`です。翻訳のモデルは別の場所で、Windowsではアプリのフォルダーの`weights`に、Linuxでは<CopyText>\~/.local/share/astarot</CopyText>（0.5.xまでは`vrct-vox`）の中に入ります。以前の版が取得したWhisperのモデルが残っていれば、同じ場所の`weights/whisper`にあります。

## 起動時の自動取得

0.5.0から、起動したときにモデルを自動で取得することはありません。「設定」→「翻訳」にあった「起動時に翻訳モデルをダウンロード」はなくなりました。モデルを取得するのは、設定や確認画面でライセンスと容量を確かめて、同意したときだけです。
