# 最初の設定

文章を翻訳してVRChatのチャットボックスへ送るところまでを設定します。読み上げや字幕は、そのあとで機能ごとのページを見ながら設定してください。

![翻訳をオンにして会話しているASTAROTのメイン画面](/screenshots/ja/main.webp)

左にスイッチと言語、右に会話のログ、下に入力欄があります。

<StepProgress />

## 1. 利用状況の送信を選ぶ

最初に起動すると、利用状況の送信をお願いする画面が出ます。「送信する」「送信しない」「あとで決める」から選んでください。どれを選んでもアプリの機能は変わりません。送る内容は[プライバシー](./privacy)にあります。

## 2. VRChatのOSCをオンにする

ASTAROTはOSCという仕組みでVRChatのチャットボックスへ文字を送ります。VRChatのアクションメニューから「Options」→「OSC」を開き、「Enabled」にしてください。

メイン画面の右上の「クイック設定」を開くと、OSCが有効なVRChatをお使いのPCで検出できたかが出ます。「設定」→「VRChat」の先頭にも同じ表示があります。

![「クイック設定」を開いたところ。VRChatを検出したと表示されている](/screenshots/ja/quick-settings.webp)

送信先は既定で<CopyText>127.0.0.1</CopyText>のポート<CopyText>9000</CopyText>です。VRChatの既定と同じなので、ふつうは変えません。変えるときは「設定」→「高度な設定」の「OSC」で変更します。

## 3. 言語を選ぶ

メイン画面の左にある「言語設定」で次の2つを選びます。翻訳はこの2つの言語の間で両方向に行います。

- 「あなたの言語」は自分が話したり入力したりする言語です。相手の発言はこの言語に訳します。
- 「相手の言語」は相手が話したり書いたりする言語です。自分の発言はこの言語に訳します。3つまで選べます。

2つの間にある「言語を入れ替え」を押すと入れ替わります。

## 4. 翻訳をオンにして送る

メイン画面の左で「翻訳」をオンにします。翻訳モデルがまだないときは、「翻訳」のスイッチは押せません。先にモデルを取得します。

- 最初の画面の「初期設定を開く」から、音声認識・翻訳・読み上げのモデルを機能ごとに選んで、まとめて取得できます。
- 翻訳のモデルだけなら、「翻訳」のスイッチの横のアイコン（「翻訳モデルの取得内容を確認」）からも取得できます。

どちらも、ライセンスと容量を確かめて同意してから取得します。取得が終わったら「翻訳」をオンにします。

初期設定は自動では開きません。終えるまでは、最初の画面の「初期設定を開く」の行が目立ちます。「完了」を押すと、準備した機能のメイン画面のスイッチ（「マイク入力」と「聞き取り」、「翻訳」、「テキスト読み上げ（TTS）」）を、オンにするまでライラックの枠で目立たせます。初期設定がスイッチをオンにしたり、設定を変えたりすることはありません。

下の入力欄に文章を入れて送信すると、原文と訳文がログに出ます。VRChatのチャットボックスにも同じ内容が出ます。

::: tip ローカルのモデルを使わないとき
外部の翻訳APIを使うときは、「設定」→「翻訳」の「詳細設定」でAPIキーを登録し、メイン画面の「翻訳エンジン」で選びます。詳しくは[翻訳](../features/translation)を見てください。
:::

会話ログが空のときにメイン画面に出る「使う前の準備」には、残っている準備が並びます。音声認識や翻訳の準備が残っているあいだは、そこに「初期設定を開く」が出ます。

## 5. マイクとスピーカーを選ぶ

声を使う機能（字幕、テキスト読み上げ、ボイスチェンジャー）を使う前に選んでおきます。メイン画面の左下の歯車から設定を開きます。

- ローカル（speech.cpp）の字幕で文字にするマイクと聞き取りの音は、「音声認識（ASR）」→「詳細設定」→「リアルタイム字幕」の「マイク入力」と「聞き取りの出力先」で選びます。初めはシステムの既定に従います（[音声認識（ASR）とリアルタイム字幕](../features/transcription)）。
- 「デバイス」の「マイク」と「スピーカー」は、クラウドの音声認識エンジンで使います。「マイク」は、ボイスチェンジャーの「転送する入力」の初期値にもなります。LinuxではPipeWireの入力が並びます。

マイクの「自動選択」はOSの既定の入力に従います。Windowsのスピーカーは、音が出ている出力にも自動で切り替わります。

## 6. 使う機能に合わせて表示を絞る

設定のメニューのいちばん上にある「用途」で、使い方を選べます。選んだ用途で使う機能だけが、メイン画面のスイッチと設定のメニューに出ます。

| 用途 | 使い方 |
|---|---|
| 基本 | 自分の声を認識して翻訳し、字幕とチャットボックスに出す。新しく入れたときはこれです |
| 無言勢向け | 声を出さずに文字で話す。相手の声やチャットを読む |
| 多言語会話向け | いくつもの言語の相手と、声で会話する |
| RVC向け | 自分の声を変えて話す。翻訳は使っても使わなくてもかまいません |
| すべて表示 | すべての機能とページを出す。前の版から更新したときはこれです |

- いくつ選んでもかまいません。選んだ用途のどれかで使う機能が出ます。
- 用途を変えても、機能のオン・オフや設定は変わりません。オンにしている機能のスイッチは、どの用途でも出ます。
- 隠れたスイッチは、スイッチの下の「ほかの機能」で出せます。隠れたページも、設定の検索で見つかります。
- 設定の各ページは、最初に使う項目が上にあります。一度決めたら変えない項目は、ページの「詳細設定」を開くと出ます。

用途の名前は、使ってみた人の声を聞いて変えることがあります。
