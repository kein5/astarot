# Linuxの音声経路

テキスト読み上げやボイスチェンジャーの声をVRChatに届けるには、ASTAROTの音声をVRChatのマイク入力へつなぐ必要があります。Linuxでは、ASTAROTが管理する仮想マイク（PipeWire）を作れます。

![「設定」→「デバイス」の画面](/screenshots/ja/device.webp)

## 管理対象の仮想マイクを使う

1. 「設定」→「デバイス」→「詳細設定」→「音声経路」で「管理対象の仮想マイク（Linux）」を選んで保存します。準備が自動で始まります。「ボイスチェンジャー（RVC）」のページの「仮想マイクを準備して使用」からも始められます。
2. 準備が終わったら「ミュートを解除」を押します。仮想マイクはミュートした状態で作られます。
3. VRChatのマイクに「VRCT Managed Virtual Microphone」を選びます。

管理者の権限は必要ありません。PipeWireと、systemdのユーザーサービスが使える環境が必要です。

### アプリがすること

- `vrct-managed-source`、`vrct-managed-tts`、`vrct-managed-vc`の3つのユーザーサービスを作り、有効にします。保存先は<CopyText>\~/.config/systemd/user/</CopyText>です。
- 仮想マイクはASTAROTを終了しても残します。次にログインしたときはミュートした状態で作り直します。
- 正しく動く仮想マイクがすでにあれば、新しく作らずにそれを使います。

### アプリがしないこと

- 音声サービス（PipeWireなど）の再起動
- マイクの録音の開始、モデルの取得
- 終了時の仮想マイクの削除。使っているアプリから突然マイクが消えると、別のマイクに切り替わるおそれがあるためです。

## ミュートと再開

「デバイス」→「詳細設定」→「音声経路」の「ミュートする」は、この仮想マイクを通る読み上げとボイスチェンジャーの声をまとめて止めます。解除するには「ミュートを解除」を押します。ASTAROTを起動し直したときはミュートした状態から始まります。

## 仮想マイクを消すとき

1. ASTAROTを終了します。
2. VRChatなど、仮想マイクを使っているアプリの入力を別のマイクに切り替えます。
3. 上の3つのユーザーサービスだけを停止して、無効にします。

```sh
systemctl --user disable --now vrct-managed-source.service vrct-managed-tts.service vrct-managed-vc.service
```

## 既存の外部ケーブルを使う

すでに仮想ケーブルなどを用意しているときは、「音声経路」を「既存の外部ケーブル」にして、「テキスト読み上げ（TTS）」の「出力デバイス」でそのケーブルを選びます。VRChatではケーブルの録音側をマイクに選んでください。このとき「ミュートする」が止めるのは、ASTAROTの読み上げだけです。
