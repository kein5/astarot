# Model downloads

ASTAROT packages contain no models for text to speech, speech recognition, translation, the voice changer or text recognition. Download the models you use from the settings, or point to files you already have. How to use files of your own is in [Use your own models](./custom-models).

## How a download works

1. Under "Download a default model" on a page, press "Review download". On "Text to speech (TTS)" and "Speech recognition (ASR)" it is inside "Models and servers".
2. Check the provider, model name, exact size, links to the terms and where it will be saved.
3. Tick the agreement and press "Agree and download". You can cancel while it downloads.
4. When the download and check finish, press "Apply model path". First stop the server or feature that uses the model.

The [first setup](./first-setup) screen can also choose the speech recognition, translation and text to speech models for each feature and download them in one go.

![The review of a model download and its terms](/screenshots/en/model-consent.webp)

Downloading or applying does not start a server, speech or the microphone.

For a speech model, once its server runs, "Play sample" on the card of the model in use lets you hear the voice on your own ([Play a sample of the voice](../features/tts#play-a-sample-of-the-voice)).

::: info File checks
Downloaded files are checked by size and SHA-256 before use. They come only from Hugging Face repositories chosen in advance, at a fixed version of each.
:::

For Japanese speech, Small MF is the standard choice: its first audio comes soonest. Small without MF and Large take longer to their first audio. Large's text encoder comes from Google's Gemma, so the [Gemma Terms of Use](https://ai.google.dev/gemma/terms) and its Prohibited Use Policy apply.

For speech recognition you can choose every model the bundled speech.cpp handles. The table gives the size of the file speech.cpp fetches by default. "File type (quantization)" offers the other types (Q4_K and so on). Smaller types take less space and memory but may make a few more mistakes.

Translation models are downloaded under Settings → "Translation" (see [Translation](../features/translation)). The list there shows the models you can download, and "Review download" opens a screen showing the source, license and size. Nothing is downloaded until you tick the consent box.

The Whisper models of earlier versions can no longer be downloaded. Speech recognition that runs on your PC uses the speech recognition models and Silero VAD in the table above ([If you used Whisper in an earlier version](../features/transcription#whisper)). Old Whisper models left on your PC (`weights/whisper`) are not removed by the app; delete the folder by hand to free the space.

## GPU and memory guidance

The "Text to speech (TTS)" page shows your GPU's name and its total and free memory, and suggests the standard or the lighter model for that free memory. This is guidance only; it does not reserve memory or guarantee that it runs. Leave more headroom when you use VRChat at the same time.

## Which GPUs are used

| Feature | GPU |
|---|---|
| Speech, realtime captions and telling speakers apart (speech.cpp, which comes with the app) | AMD, Intel and NVIDIA (Vulkan) |
| Local translation | NVIDIA with CUDA, or on Windows, a DirectX 12 GPU with DirectML. Both need their runtime downloaded first |
| Translation LLMs (TranslateGemma and other GGUF files you add) | AMD, Intel and NVIDIA (the Vulkan build of llama.cpp's server, downloaded first) |
| Voice changer (RVC) | NVIDIA with CUDA, or from 0.6.0 on Windows, a dedicated DirectX 12 GPU with DirectML (Automatic never uses integrated graphics). The CPU can also convert if it is fast enough for live audio ([Voice changer](../features/voice-conversion)) |
| Chat reading | Runs on the CPU |

Under "Models and servers", Automatic selects the dedicated Vulkan GPU with the most memory among those available for computation. It uses the CPU if none is available. You can also select a dedicated GPU by name.

To translate on an AMD or Intel GPU, download the DirectML build of ONNX Runtime on Windows, run a translation LLM on llama.cpp's server, or use a [local LLM](../features/translation#use-local-llms-and-compatible-servers): Ollama and LM Studio support those GPUs too.

## Where models are saved

Downloaded models go to `downloaded_models` in the same folder as the settings file (`config.json`). On Linux that is <CopyText>\~/.config/astarot/downloaded_models</CopyText> (in the `vrct-vox` folder up to 0.5.x); on Windows it is `downloaded_models` in the folder the app is in. Translation models go to the same `downloaded_models`. Folders from earlier versions under `weights` (such as Whisper's `weights/whisper`) stay in the data folder (the app's folder on Windows, <CopyText>\~/.local/share/astarot</CopyText> on Linux).

## Downloading at startup

From 0.5.0 the app never downloads a model on its own when it starts. "Download the translation model at startup" is gone from Settings → "Translation". A model is downloaded only when you check its license and size in the settings or in a confirmation and agree.
